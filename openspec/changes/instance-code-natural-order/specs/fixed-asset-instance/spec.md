# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 实例编号自然排序

实例列表与导出 MUST 按内部编号的**数字自然序**输出（同前缀下 `-1, -2, … -9, -10, -11`），MUST NOT 出现字符串字典序的跨位数乱序（`-1, -10, -2`）。实现 SHALL 用 `(编号长度, 编号)` 复合排序键（同前缀先短后长、同长字典序 = 数字序），保持跨库兼容且不改编号格式。

#### Scenario: 跨位数顺序

- **WHEN** 某分公司某品目存在实例 -1..-12，用户打开实例档案列表
- **THEN** 顺序为 -1, -2, …, -9, -10, -11, -12（而非 -1, -10, -11, -12, -2, …）
