# ledger-single-source Specification（修改）

## MODIFIED Requirements

### Requirement: 台账页面的只读化呈现

台账页面（`/assets/summary`）为资产主视图，SHALL 以 Excel 式朴素表格展示：序号、分公司、资产编号、名称、规格、资产类目、管理方式、在库、在用、回收库、总量、警戒线、是否充足。页面 MUST NOT 提供直接新增/编辑/删除台账行的入口，数量修正 MUST 经调整单；「是否充足」为否时 MUST 以醒目样式标识。

实例管理品目行 MUST 提供实例下钻：行内展示各状态实例计数，点开抽屉呈现该（分公司×品目）实例列表（内部编号、序列号、状态、使用人），并携带序列号补录与实例生平入口；数量管理品目行 MUST NOT 出现实例下钻。台账增量导入为存量初始化的唯一入口（差异预览 → 确认生成期初调整单）。

#### Scenario: 页面无直接写入口

- **WHEN** 持管理权限的用户打开台账页
- **THEN** 表格可见 13 列，无「新增」「编辑」「删除」按钮（导入入口保留）

#### Scenario: 库存不足醒目标识

- **WHEN** 某行在库数量低于生效警戒线
- **THEN** 「是否充足」列显示「否」并以警示样式呈现

#### Scenario: 实例管理行下钻

- **WHEN** 用户点击某实例管理品目行的「实例」
- **THEN** 抽屉展示该分公司×品目全部实例（含退役），可补录序列号、跳转生平

#### Scenario: 数量管理行无下钻

- **WHEN** 某行品目为数量管理
- **THEN** 行内无实例下钻入口
