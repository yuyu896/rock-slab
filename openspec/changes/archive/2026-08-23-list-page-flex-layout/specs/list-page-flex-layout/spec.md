## ADDED Requirements

### Requirement: 列表页纵向 flex 布局契约
PC 端（MainLayout 内容区）所有带数据表格的列表页 SHALL 采用统一纵向 flex 布局：页面根节点占满内容区可用高度；页头、筛选区、统计区 MUST NOT 被压缩；数据表格区域 SHALL 以 `flex: 1` 撑满剩余高度并在容器内部滚动；分页条 MUST 钉在页面底部不被压缩。表格高度 MUST NOT 使用 `calc(100vh - …)` 之类按屏高估值的魔法数字。

#### Scenario: 任意屏高表格撑满
- **WHEN** 用户在任意窗口高度（如 700px 与 1400px）打开列表页
- **THEN** 页头与筛选区完整可见，表格占据内容区剩余全部高度，页面自身无整页滚动条，仅表格内部滚动

#### Scenario: 分页钉底
- **WHEN** 列表页数据行数超过表格可视高度
- **THEN** 表格内部滚动，分页条始终贴合内容区底边可见可点，无需滚动页面寻找

#### Scenario: 矮屏保底
- **WHEN** 窗口高度过矮导致页头+筛选区几乎占满内容区
- **THEN** 表格区域仍保留最小可视高度，超出部分由内容区兜底滚动，页面结构不被压缩错位

### Requirement: 内部滚动表格的表头常驻
列表页表格改为内部滚动后，表头行 SHALL 采用 sticky 定位：用户在表格内纵向滚动时列标题 MUST 保持可见，且表头 MUST 使用不透明背景防止行内容透出。

#### Scenario: 滚动时表头可见
- **WHEN** 表格内部滚动到第 N 行（N 大于可视行数）
- **THEN** 列标题行仍固定于表格容器顶部

### Requirement: 非列表页滚动行为不变
MainLayout 内容区 SHALL 保持对非列表页的整页滚动能力：工作台、新建、详情等自然高度页面内容超出可视高时，MUST 由内容区滚动呈现，布局与改造前一致。

#### Scenario: 详情页照旧滚动
- **WHEN** 用户打开内容高度超过视口的新建/详情页
- **THEN** 内容区出现整页滚动条，页面排版与列表页改造前一致

### Requirement: 多视图页在列表视图下同样填满
含列表/详情等多视图切换的页面（盘点管理、采购入库）SHALL 在列表视图下满足 flex 填充契约；切换到详情/新建等视图时 SHALL 由页面根节点内部滚动呈现超高内容。

#### Scenario: 盘点列表填满、详情可滚
- **WHEN** 用户在盘点管理页的任务列表视图与任务详情视图间切换
- **THEN** 列表视图表格撑满内容区且分页/操作可见；详情视图超高时页面内部滚动

### Requirement: 列表页默认每页 50 条
PC 端列表页（含 BasePagination 组件默认值与各页初始查询参数）SHALL 默认每页 50 条；用户 MUST 仍可通过每页条数选择器调整（可选值含 10/20/50/100）。

#### Scenario: 首次进入列表页
- **WHEN** 用户首次进入任一列表页（未手动调整过每页条数）
- **THEN** 列表一次加载并展示至多 50 条，分页条「每页」显示 50

#### Scenario: 手动调整每页条数
- **WHEN** 用户将每页条数改为 20
- **THEN** 列表按每页 20 条重新加载并翻回第 1 页
