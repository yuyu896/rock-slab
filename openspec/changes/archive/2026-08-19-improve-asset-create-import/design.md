## Context

- `Asset` 模型：`序号`(IntegerField, ordering=['-序号'])、`所属部门`(CharField)、`警戒线`(IntegerField null)。
- `Category` 模型：`warning_line`(IntegerField '警戒线')——警戒线联动数据源。
- `/api/categories/lookup`（既有）现返回 资产名称/资产类目/物品分类/计量单位。
- 资产导入（`assets/views.py import_excel`）**按列位置**解析：`序号=row[0]`、`警戒线=row[20]`；下载模板 `download_template` 的表头含「序号」「警戒线」。
- 资产导入模板表头：`['序号','分公司','资产编号','分公司编号','资产类目','电脑序列号','供应商','物品分类','资产名称','图片','入库日期','是否租用','数量','规格','单价','购入金额','出库日期','所属部门','使用人','当前状态','警戒线','是否充足','备注']`。
- 新增资产表单（`AssetCreatePage`）目前无「警戒线」字段，资产编号失焦联动带出 名称/类目/分类（`useAssetCodeAutofill`）。
- 系统无 Department 主数据；`所属部门` 为自由文本。

## Goals / Non-Goals

**Goals:**
- 所属部门用固定列表下拉，避免不一致。
- 警戒线由分类（按编号反查）决定，导入与新增一致。
- 序号为系统自动行序号，随筛选变化；导入模板不再含序号/警戒线列。

**Non-Goals:**
- 不新增 Department 模型（用前端固定列表常量）。
- 不删除/迁移 `Asset.序号` 字段（保留用于默认排序，仅改导入与展示）。
- 不改单条编辑（`AssetEditDrawer`）的所属部门为下拉（仅新增表单；可后续复用常量）。
- 不重算历史资产的序号/警戒线（仅影响新增/导入与列表展示）。

## Decisions

### 决策 1：所属部门 = 前端固定列表常量
- **做法**：`constants` 加 `DEPARTMENT_OPTIONS`（固定列表）；`AssetCreatePage` 所属部门改 `<select>`。
- **理由**：用户裁定为固定列表；无需新主数据，前端常量易维护。
- **待确认**：具体部门名称 = `['行政部','财务部','人事部','业务部','其他']`（已定）。

### 决策 2：警戒线由分类决定（扩 lookup + 导入取分类）
- **做法**：`/api/categories/lookup` 返回增加 `警戒线`；资产导入按 `资产编号` 反查分类取 `warning_line`（不读模板列）；`AssetCreatePage` 失焦联动（`useAssetCodeAutofill`）一并带出警戒线到 `newAsset.警戒线`。
- **理由**：编号唯一对应分类，分类的警戒线是权威来源；导入与新增一致。
- **备选**：导入仍读模板列——会不一致，**否**。

### 决策 3：序号 = 列表行序号（展示）+ 导入自动分配（存储）
- **做法**：`AssetList` 序号列渲染 `(page-1)*pageSize + 行内序 + 1`（当前筛选/分页内连续行号，随分公司筛选变化）；导入模板去「序号」列，导入不再读序号，存储序号自动分配（`max(序号)+1`，保持默认排序）。
- **理由**：满足「自动排序 + 随筛选变化」；存储字段保留以维持默认排序，避免模型迁移。

### 决策 4：导入模板去「序号」「警戒线」两列 → 导入解析需调整
- **做法**：模板表头移除「序号」「警戒线」；导入解析相应调整。资产导入现为**按列位置**解析，移除两列后索引位移——**推荐顺手把资产导入改为按表头列名映射**（与固定资产导入一致），使去列更稳、抗列序变动。
- **理由**：按位置解析在去列后极易错位；按列名映射更稳。
- **备选**：仅重新编号位置索引——脆弱，**否**。

## Risks / Trade-offs

- **[固定部门名称待定]** 常量值需用户确认 → **缓解**：先用占位默认，实现时确认。
- **[导入列位移]** 去序号/警戒线列后位置解析错位 → **缓解**：改按列名映射（决策 4）。
- **[历史数据]** 旧资产序号/警戒线不变 → **接受**，仅影响新增/导入与展示。
- **[分类未登记]** 编号未登记时警戒线为空 → **缓解**：导入已校验编号存在（既有），未登记行本就被拒；联动为空时保留空。

## Migration Plan

1. 后端：lookup 加警戒线；导入去序号/警戒线列、改按列名映射、序号自动分配、警戒线取分类。
2. 前端：所属部门下拉 + 常量；警戒线联动；序号行号渲染。
3. 纯前后端逻辑，**无 DB 迁移**；部署即生效。
