# A4 三列成品纸版式 — 技术设计

## Context

A4 通道现版式：grid 双列自适应卡片（px 字号），`@page { size: A4; margin: 8mm }`，一页约 14 枚——为普通 A4 纸裁切设计。现改用成品 21 枚不干胶纸（3 列×7 行，单枚 63.8×38mm，A4 竖向 297×210），版式必须与裁切位精确对齐，否则内容骑格。

60×40 通道（单签版式）与导出图片通道（`labelImage.ts`，960×640）继续服务汉印 M1，不动。

## Goals / Non-Goals

**Goals:**

- A4 打印输出与成品 21 枚纸裁切位对齐：3 列×63.8mm、列距 3mm、行距 0、左右边距 6mm、上下边距 15.5mm 居中、每页 21 枚。
- 预览所见即所得（mm 真实几何）。
- 60×40 单签与导出图片通道行为不变。

**Non-Goals:**

- 不动 60×40 版式、不动导出图片（960×640）。
- 不做按筛选全量打印增强。
- 不做打印偏差校准 UI（若某台打印机走纸有系统性偏差，后续按需另立）。

## Decisions

### D1：A4 版式改「真实 mm 几何」，复用 60×40 的标签内部规范

`.paper-a4` 下卡片从自适应 px 改为定死 `63.8mm × 38mm`（border-box、padding 1.5mm），内部行集/前缀/QR/字号直接沿用 `.paper-60x40` 的 mm 参数（LABEL_SPEC 同源）：QR 13mm+2mm 静区、NO/SN/ITEM/BRANCH/VENDOR·DATE 五行、3.4/3.0/3.4/2.6mm 字号、缩号下限 2.2mm。文字可用宽 `63.8 − 1.5×2 − 17 − 1.5 = 42.3mm`（比 60×40 的 38.5mm 宽 3.8mm，超宽行更不易触发缩号）。

理由：两个纸型共享同一套标签内容规范，A4 只是把这份规范铺到 63.8×38 的格里；缩号测量（fitLabelLines 读 clientWidth）在 mm 几何下屏显与打印一致，比现 px 自适应更准。
备选「A4 独立一套 px 版式」会造成三处参数漂移（打印 CSS/导出/LABEL_SPEC），弃。

### D2：@page 边距 `15.5mm 6mm`，行距 0 打印态生效

```css
@page { size: A4; margin: 15.5mm 6mm; }   /* 内容区 198×266mm，恰好 3 列/7 行 */
.paper-a4 .print-labels { grid-template-columns: repeat(3, 63.8mm); column-gap: 3mm; }
```

上下 16mm 口述值与 7×38 相加为 298mm 超页高 1mm（第 7 行掉页），取 31mm 余量对半 15.5mm；与 16mm 的差每边 0.5mm，在走纸公差内。**预览与打印行距同为 0**（成品纸贴格、所见即所得；曾试预览留 4mm 便于分辨边界，用户定案不要——源码契约测试断言基础规则不得引入 row-gap）。

### D3：A4 纸型下打印弹窗加宽，预览真尺寸三列

三列真尺寸宽 197.4mm ≈ 747px（96dpi），现弹窗内宽约 752px 减滚动条约 15px 后放不下。`.print-modal.paper-a4 { max-width: 860px }`（60×40 不变 800px），窄屏回落 `width: 90%` + `.print-labels` 横向滚动兜底。

### D4：分页与容量

grid 自动分行，卡片 `break-inside: avoid` 不变；行高恰 38mm×7=266mm=内容区高，每页正好 21 枚、无第 8 行空间。100 条勾选上限 = 5 页（原 7 页）。

## Risks / Trade-offs

- [打印机走纸系统性偏差（>1mm）导致骑格] → 用户以「实际大小/100%」打印为前提；若个别机器有偏差，后续可加全局 mm 微调（另立变更）。手验时用成品纸实打一页核对四角。
- [mm 字号屏显偏小（3.4mm≈12.9px）] → 弹窗内即打印原样，用户以打印效果为准；预览横滚仅在窄屏出现。
- [源码契约断言需同步 A4 参数] → 沿用 `?raw` 源码断言惯例，参数进断言（63.8/38/3mm/15.5mm/6mm/三列）。

## Migration Plan

纯前端 CSS/版式改动，随常规发版；60×40 与导出通道不受影响，无回滚风险。上线后提醒各分公司：A4 批量打印改用 21 枚成品纸、容量 21 枚/页。
