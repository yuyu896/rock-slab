# 设计：标签版式调整 V2

## Context

标签规范 V1（QR + 内部编号 + 60×40/A4 双轨 + 导出图片通道）已上线并经 M1 实机验收。用户实测反馈三点：分公司应从品目行拆出、缺供应商/采购日期、内容偏下且字号偏小。版式参数在打印 CSS（`AssetPrintDialog.vue`）与 canvas（`utils/labelImage.ts` 的 `LABEL_SPEC`）两处同源维护，本条改动两侧同步。

## Goals / Non-Goals

**Goals:**

- 辅助信息分三行：品目编号 / 分公司 / 供应商·采购日期，层次清晰
- 供应商、采购日期上签，空值按规则隐藏不占位
- 全线字号上调、行距收紧，视觉居中（不偏下）
- 打印与导出图片两条通道版式一致

**Non-Goals:**

- 不改 QR 码制/尺寸（13mm + 2mm 静区不变）
- 不改 A4 双列版式的字号（卡片空间充裕，仅同步新增文案行）
- 不做竖版 40×60（M1 用 App 旋转打印已解决）

## 版式（60×40 横版，两通道同参）

```
┌──────────────────────────────────────┐
│ ┌────┐   A-a00008-BJ001-1   3.6mm 粗 │
│ │ QR │   SN: PF3XK2LM        3.0mm   │
│ │13mm│   笔记本电脑           3.4mm 粗│
│ └────┘   品目 A-a00008       2.6mm   │
│          北京分公司           2.6mm   │
│          联想 · 2026-08-15    2.6mm   │
└──────────────────────────────────────┘
  行距 0.5mm · 行高系数 1.2 · 整块垂直居中后再上移 0.4mm
```

行集共 6 行，总高约 23.9mm，与 QR 块（17mm）均在 37mm 可用高度内。

## Decisions

**D1：供应商与采购日期合并一行**

「<供应商> · <采购日期>」：合并行让 6 行控制在 24mm 内，留出字号上调的空间；两项皆空整行隐藏、单项空只留存在项，与 SN 隐藏规则同风格。

**D2：视觉居中校正 = 居中后上移 0.4mm**

canvas 绘制基线在行盒顶部 + 字号处，行盒底部留有 0.2×字号 的下行空隙（descent），逐行累积使文字块视觉重心下沉；打印 CSS 的行盒同理。块垂直居中后再整体上移 0.4mm（约一行下行空隙的一半），两侧同参数。

**D3：字号/行距参数只改 60×40 通道**

`LABEL_SPEC` 与 60×40 的 CSS 同步调整；A4 双列卡片沿用 px 字号，仅追加新文案行（分行规则一致），避免 A4 卡片因 mm 字号显得失衡。

**D4：toPrintShape 透传**

供应商、采购日期自实例接口字段（`item.供应商`、`item.采购日期`）透传，空值规整为空串由弹窗按隐藏规则处理。

## Risks / Trade-offs

- [6 行 + 更大字号在极端长内容（超长供应商名）时触发缩号] → 缩号规则兜底（下限 2.2mm），主行内部编号不受影响
- [两通道参数手工同步漂移] → `LABEL_SPEC` 注释与打印 CSS 注释互相指向（既有约定），源码断言测试覆盖关键参数
