# 实例点选器去重与收口——跨行排除已选 + 面板完成即关

## Why

绑定类单据（领用/调拨/回收/归还）明细行的实例点选器（InstancePicker）有两个实测体验问题：

1. **跨行可重复选**：每行独立拉同一候选集，行 2 的候选仍含行 1 已选实例，可再次勾选。后端有单内重复引用拒绝兜底（ledger 不变量：防台账计双份），提交时必被拦——但用户填完整张单才收到报错，白费一轮。
2. **面板不收口**：候选面板为常开多选勾选，勾选不收起；多行面板可同时展开，屏幕上同时出现多个「选择实例」按钮+面板，观感混乱。期望：选择完成后关闭面板，格子显示已选实例。

## What Changes

- 实例点选器新增排除入参：编辑器汇总**全部明细行**已选实例 id 传入，候选列表直接排除他行已选；本行已选保留勾选回显
- 候选面板加「完成」按钮（展示已选台数），点击收起面板；收起后仅显示已选编号回显（既有行为）
- 同屏互斥：展开任一行的面板时自动收起其他行已展开的面板
- 非目标：不改一行多台的多选能力（数量=勾选台数联动契约保持）；不动后端（重复引用终检兜底保留）

- 后端、API、数据不动
