# design — 北京三分手动点删（单实例行形态）

## Context

目标出生链：CG20260806-023（单行 ×1）→ 本台。多实例行点删（nb33）的"行数量减 N"在 N=行数量 时留零值行——单实例行归零后行无意义，删行；单据空行则连单删（零行单据是死档案）。对账数学不变：删行/删单使流水贡献 −1，存储同减，镜像同减。

## Decisions

### D1. 归零删行、空行删单

`行数量 − 被删数 == 0` → 删该行（其 TransferLineInstance 随行级联）；单据剩余 0 行 → 删单 + 关联通知。多行单据仅删目标行，其余行原样。

### D2. 断言沿用 nb33 体系

存在/本分公司/在库/仅出生链/生效采购单/行账一致/镜像一致。算量实时（回退量=被删行数量）。

## Migration Plan

push → 部署 → 备份 → dry-run（行 1→0 删行删单、台账 49→48）→ `--apply` → 对账+抽查 → 幂等复证。
