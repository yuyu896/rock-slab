## ADDED Requirements

### Requirement: 所有流转单据支持草稿

系统 MUST 为采购入库、领用出库、归还、调拨和回收单据提供一致的草稿生命周期。草稿沿用单据现有的关键单头字段和至少一条有效明细校验；经授权的用户 MUST 能保存并继续编辑草稿，且草稿 MUST NOT 进入审批或改变台账、库存。

#### Scenario: 保存完整单据为草稿
- **WHEN** 用户在五类流转单之一填写了必要单头字段和至少一条有效明细，并选择保存草稿
- **THEN** 单据以草稿状态保存，用户可后续打开并继续编辑，且不产生审批通知或台账、库存变动

#### Scenario: 缺少必要信息时保存草稿
- **WHEN** 用户保存的单据缺少现有校验要求的关键字段或有效明细
- **THEN** 系统拒绝保存并指出校验问题，单据状态和台账、库存均不改变

#### Scenario: 从草稿提交审批
- **WHEN** 用户完成草稿编辑并选择提交审批
- **THEN** 单据进入待审批状态，审批通知按现有规则发送，且后续业务效果仍只在原有生效节点发生

### Requirement: 创建人可以撤回待审批单据

系统 MUST 允许流转单据的创建人撤回处于待审批状态的单据，并将其恢复为可编辑草稿。创建人身份 MUST 通过 `created_by` 账号关联判定，不得通过姓名、岗位或客户端参数判定。撤回应记录审计日志且 MUST NOT 改变台账、库存。

#### Scenario: 创建人撤回待审批单据
- **WHEN** 当前认证用户是待审批单据的 `created_by`，并确认撤回操作
- **THEN** 单据转为草稿，保留原单头及明细，可继续编辑和提交，且不改变台账或库存

#### Scenario: 非创建人请求撤回
- **WHEN** 非创建人请求撤回待审批单据，包括与创建人同名的其他账号
- **THEN** 后端拒绝请求，单据状态、台账和库存保持不变

#### Scenario: 撤回非待审批单据
- **WHEN** 用户请求撤回草稿、已驳回、已通过、已入库或其他非待审批状态的单据
- **THEN** 后端拒绝请求并返回明确的状态错误，单据和台账数据保持不变

#### Scenario: 撤回与审批并发
- **WHEN** 创建人撤回与审批人处理同一待审批单据同时发生
- **THEN** 系统串行校验单据状态，仅一个有效状态转换成功，另一个请求收到状态冲突，不覆盖已完成的状态转换

### Requirement: 前端按单据状态提供生命周期操作

系统 MUST 在已有的 Web 和移动端流转单创建入口提供草稿保存与提交审批操作；详情或列表 MUST 按单据状态显示可用的继续编辑、提交、撤回或驳回后重提操作。撤回入口 MUST 仅在服务端返回 `canWithdraw=true` 时显示，且前端显示逻辑不得替代后端权限校验。

#### Scenario: 创建页面显示草稿操作
- **WHEN** 用户打开已有的流转单创建页面
- **THEN** 页面同时提供保存草稿和提交审批操作

#### Scenario: 创建人查看待审批单据
- **WHEN** 创建人查看本人待审批单据且服务端返回 `canWithdraw=true`
- **THEN** 页面显示撤回操作，确认成功后显示可编辑草稿内容

#### Scenario: 非创建人查看待审批单据
- **WHEN** 用户查看他人待审批单据且服务端返回 `canWithdraw=false`
- **THEN** 页面不显示撤回操作

#### Scenario: 编辑驳回单据后重新提交
- **WHEN** 用户按现有编辑权限打开已驳回单据并完成修改
- **THEN** 页面允许重新提交，单据按现有重提规则回到待审批状态

#### Scenario: 仅可编辑者看到草稿和驳回单据的编辑入口
- **WHEN** 用户查看草稿或已驳回单据
- **THEN** 系统仅在服务端返回 `canEditDraft=true` 时显示编辑入口，且后端继续独立校验创建人或管理员权限

### Requirement: 移动端用户可重新打开本人草稿

移动端审批中心 MUST 提供本人草稿列表入口。草稿列表查询 MUST 由服务端按当前认证账号的 `created_by` 过滤，不得通过客户端姓名筛选；用户 MUST 能从列表打开相应类型现有的草稿编辑页面。该要求不新增尚不存在的移动端归还录入页面。

#### Scenario: 打开本人移动端草稿
- **WHEN** 用户在移动端审批中心打开“我的草稿”并选择本人草稿
- **THEN** 系统仅返回当前账号创建的草稿，并导航至可编辑该单据的页面

#### Scenario: 不能查询其他账号的草稿
- **WHEN** 用户通过本人草稿查询参数请求列表
- **THEN** 服务端只返回 `created_by` 等于当前认证账号的草稿，不受客户端传入的姓名影响
