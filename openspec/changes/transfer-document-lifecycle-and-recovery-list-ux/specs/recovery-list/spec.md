## ADDED Requirements

### Requirement: 回收列表长备注不挤压操作入口

回收列表 MUST 限制备注列宽度，并在列表中对超长备注单行省略；用户 MUST 能在单据详情中查看完整备注。操作列 MUST 固定在表格右侧，使其在横向滚动和窄视口下仍保持可见和可操作。

#### Scenario: 长备注在列表中省略
- **WHEN** 回收单备注长度超过列表列可展示宽度
- **THEN** 备注单元格按单行省略显示，不改变操作列位置或宽度，完整备注可在详情中查看

#### Scenario: 横向滚动时操作列保持可见
- **WHEN** 用户在窄视口查看需要横向滚动的回收单列表
- **THEN** 操作列固定在表格右侧并保持可见，用户无需将整张表滚动到最右端才能使用行操作
