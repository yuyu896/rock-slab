# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 实例批量维护端点

系统 SHALL 提供实例批量维护端点（`POST /api/assets/fixed-assets/batch-update`，`manage_instances` 权限）：入参为实例 id 数组 + 待设字段；**白名单字段**为 `供应商`（写各实例出生行的 供应商 列；无出生行的实例跳过并在结果中说明）、`备注`（直写实例备注）、`序列号`（配合 ids 逐台一一对应数组，逐台校验非空与唯一，冲突行报错跳过）。状态/使用人/分公司等非白名单字段 MUST 400 拒绝。响应 MUST 返回逐台成功/失败明细。

#### Scenario: 批量改供应商

- **WHEN** 持权者勾选 3 台实例（均有出生行）批量设置供应商=联想
- **THEN** 3 条出生行供应商更新，实例档案供应商立即显示联想

#### Scenario: 批量补序列号一一对应

- **WHEN** 提交 3 台实例 id 与 3 个序列号（其一与既有实例重复）
- **THEN** 2 台成功回填，重复台在响应 errors 中点名跳过

#### Scenario: 非白名单字段被拒

- **WHEN** 批量请求携带 当前状态 字段
- **THEN** 返回 400，仅 供应商/备注/序列号 可批量维护

### Requirement: 实例列表批量操作菜单

实例档案页勾选后 SHALL 提供「批量操作」菜单：批量打印标签（既有）、批量修改供应商、批量修改备注、批量补录序列号（连续扫码逐台回填交互）——后三者均走批量维护端点且仅 `manage_instances` 可见。

#### Scenario: 菜单聚合

- **WHEN** 用户勾选 2 台实例
- **THEN** 出现「批量操作」入口，展开含打印标签/修改供应商/修改备注/补录序列号四项
