# transfer-line-items 增量

## ADDED Requirements

### Requirement: 采购明细行行级供应商

`TransferLine` SHALL 支持可选 `供应商` 字段（记录性，max 200，默认空）：采购导入/页面创建的每行可各自携带供应商，留空 MUST 继承单头供应商语义（展示层回退）。实例档案/生平的供应商派生 MUST 为 **出生行供应商 → 单头供应商** 依次回退（与规格派生同构）。领用/调拨/回收行 MUST NOT 携带该字段（供应商为采购语义）。

#### Scenario: 一单两供应商

- **WHEN** 采购单两行（行 1 供应商=联想、行 2 供应商=华为、单头供应商=默认）
- **THEN** 两行各自展示其供应商；各自出生实例的档案供应商分别显示联想/华为

#### Scenario: 行空回退单头

- **WHEN** 采购行未填供应商、单头供应商=戴尔
- **THEN** 该行及出生实例的供应商显示戴尔
