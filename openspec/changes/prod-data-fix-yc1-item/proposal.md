## Why

盐城分公司的 34 台"笔记本电脑"（A-a00008）实为**电脑（一体机）**（A-a00011），员工导入时品目录错，用户要求更正（2026-09-18，编号同步换号已拍板）。佐证：34 台序列号（A24734JBL…）与北京三分/五分一体机序列号模式一致。实测形态极干净：全部出生于一张纯单 CG20260911-016（单行 ×34）、全在库、无生平单据、无调整单、无待审批行；A-a00011 在盐城零台账零实例零发号（换号 1~34 空闲）。

## What Changes

- 新增一次性纠错管理命令 `prod_data_fix_yc1_item`（默认 dry-run，`--apply` 执行，单事务）——**品目整体更正**，四处同批联动：
  1. 出生行 item：A-a00008 → A-a00011（流水重算随之迁移 +34）；
  2. 34 个实例 item 更正、内部编号换号 `A-a00008-YC001-N` → `A-a00011-YC001-N`（序号 1:1 保留）；
  3. 台账迁移：笔记本行清零删除、新建一体机行 在库 34（存储与流水同步移动）；
  4. 发号行：新建 A-a00011@盐城 last_no=34；A-a00008 发号行保留（空号不回收）。
- 前置断言：目标全在库且仅出生链（生平行数=1）、出生行行账一致（数量==出生实例数）、两品目在盐城无调整单/待审批行/错挂、目标编号全局无占用、镜像一致。
- 保留：序列号、单价/金额、供应商、单号、日期；他分公司 44 台笔记本与盐城其他品目零波及。
