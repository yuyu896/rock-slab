## ADDED Requirements

### Requirement: 品目整体更正

生产纠错命令 SHALL 支持把某分公司某品目的全部实例整体更正为另一品目（员工录错品目场景），四处 MUST 同批单事务联动：①出生明细行 item 更正（流水重算随之迁移）；②实例 item 更正并按 `{新品目编号}-{分公司代码}-{原序号}` 换号（序号 1:1 保留）；③台账存储值同侧迁移（原品目行清零删除、新品目行新建或累加）；④新品目发号行建立（last_no=最大新序号），原品目发号行保留。前置 MUST 断言：目标实例全在库且仅有出生链（生平行数==1，有生命周期单据即中止转人工）、出生行行账一致、两品目在该分公司无调整单与待审批行、新编号全局无占用、镜像一致。序列号/单价/供应商/单号/日期 MUST 保留；他分公司与同分公司其他品目 MUST 零波及。

#### Scenario: 纯出生链整批更正

- **WHEN** 某分公司 34 台品目 A 全出生于一张纯单（单行 ×34，无生平），命令以 `--apply` 更正为品目 B
- **THEN** 出生行 item 更正、34 实例 item 与编号换为 B 前缀（序号不变）、台账从 A 行迁至 B 行、B 发号行建立 last_no=34
- **AND** `check_ledger_consistency` 零差异，序列号/单价/供应商保留

#### Scenario: 有生命周期单据时拒绝

- **WHEN** 目标实例存在出生链以外的单据行关联（领用/归还/回收）
- **THEN** 命令断言失败中止，零变更（品目迁移破坏生平语义，转人工）

#### Scenario: 新编号被占用时拒绝

- **WHEN** 任一目标新内部编号已存在于系统
- **THEN** 命令断言失败中止，零变更
