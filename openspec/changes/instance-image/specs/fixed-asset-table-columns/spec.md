# fixed-asset-table-columns 增量

## MODIFIED Requirements

### Requirement: 实例表新列布局

固定资产实例表 SHALL 展示：**图片（第一列，置于序号列前，已挂图显示缩略图、未挂图显示占位，点击已挂图放大预览）**、序号、分公司、内部编号、品目编号、品目名称、规格、序列号（空=「待补录」醒目标识）、当前状态、使用人、部门、入库日期、供应商（出生行派生，存量为备注折叠值则空）、采购日期（出生行派生）。筛选 MUST 支持：分公司、状态、品目（编号/名称关键字）、序列号待补录。操作列 MUST 含「补录」与「图片」（均 `manage_instances` 权限者可见）、「生平」；「图片」按钮弹窗内提供上传/更换/删除（删除需确认），成功后列表缩略图即时更新。Excel 导出列布局保持不变（不含图片列）。

#### Scenario: 图片列置于序号前

- **WHEN** 用户打开固定资产实例页
- **THEN** 表头第一列为「图片」、第二列为「序号」，其后列布局与既有口径一致

#### Scenario: 缩略图与放大预览

- **WHEN** 某实例已挂物品图片
- **THEN** 该行图片列显示小尺寸缩略图，点击放大查看原图；未挂图实例显示占位标识

#### Scenario: 上传图片弹窗

- **WHEN** 持 `manage_instances` 权限的用户点击某实例「图片」按钮并上传 JPG 成功
- **THEN** 弹窗关闭提示成功，列表该行图片列显示新缩略图

#### Scenario: 删除图片需确认

- **WHEN** 用户在图片弹窗中点击删除并确认
- **THEN** 图片被删除，该行图片列回到占位标识

#### Scenario: 新列表头展示

- **WHEN** 用户打开固定资产实例页
- **THEN** 表头按新列布局展示，品目列由 item 联查、供应商/采购日期由出生行派生

#### Scenario: 待补录标识与筛选

- **WHEN** 某实例序列号为空，用户筛选「待补录」
- **THEN** 该行序列号列显示醒目的「待补录」标识，且出现在筛选结果中

#### Scenario: 补录弹窗

- **WHEN** 持 `manage_instances` 权限的用户点击某实例「补录」
- **THEN** 弹窗仅含 序列号/备注 两字段，提交后列表刷新，标识消失
