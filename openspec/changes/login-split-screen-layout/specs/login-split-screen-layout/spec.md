## ADDED Requirements

### Requirement: 登录页采用左右分栏布局

宽屏（视口宽度 ≥ 960px）下，登录页 MUST 分为左右两栏：左侧视觉区与右侧登录表单区，各约占 50%。右侧登录表单 MUST 在其栏内垂直居中。两栏等高铺满视口。

#### Scenario: 宽屏显示左右分栏

- **WHEN** 用户在视口宽度 ≥ 960px 的设备访问登录页
- **THEN** 页面左侧显示业务插画视觉区、右侧显示登录表单，两栏并列且等高

### Requirement: 左侧以品牌 logo 为主 + 轻量场景元素

左侧视觉区 MUST 以磐盘品牌 logo（`brand` 变体）为视觉主体，配「磐盘」标识与产品标语，并可叠加轻量场景元素（少量资产 / 勾选小图标作氛围）。所有图形 MUST 使用设计令牌着色，MUST NOT 引用外部图片文件（`<img>` / 外链资源）。

#### Scenario: 左侧以 logo 为主渲染且无外部图片请求

- **WHEN** 登录页加载完成
- **THEN** 左侧以品牌 logo 为视觉主体展示，配标识与标语；不发起额外图片资源请求；配色随品牌令牌

### Requirement: 窄屏退化为单栏表单优先

窄屏（视口宽度 < 960px）下，登录页 MUST 退化为单栏：隐藏或弱化左侧插画区，登录表单 MUST 全宽居中显示，插画 MUST NOT 挤压或遮挡表单，保证移动端登录可用。

#### Scenario: 移动端单栏登录可用

- **WHEN** 用户在视口宽度 < 960px 的设备访问登录页
- **THEN** 页面显示全宽居中的登录表单，用户可正常输入手机号 / 密码并提交

### Requirement: 深色模式自适应

登录页（含插画、背景、表单）MUST 通过 `prefers-color-scheme: dark` 自适应深色模式，复用 `styles/variables.css` 的深色令牌；MUST NOT 出现对比度不足、颜色写死导致错乱、或插画在暗色下不可辨识的情况。MUST 尊重 `prefers-reduced-motion`（插画如有动效则禁用）。

#### Scenario: 深色模式下可辨识

- **WHEN** 用户系统处于深色模式访问登录页
- **THEN** 背景 / 表单 / 插画均切换为深色配色，文字与插画元素对比度清晰可辨

### Requirement: 登录逻辑保持不变

改造 MUST NOT 改动登录的脚本逻辑：手机号 / 密码校验、`localStorage` 清理失效 token、`token_expired` 过期提示、登录请求与跳转、错误提示与显示密码切换，全部保持原行为。

#### Scenario: 登录流程行为不变

- **WHEN** 用户输入手机号与密码并提交（含校验失败 / 登录失败 / 成功跳转各路径）
- **THEN** 校验、请求、跳转、错误提示行为与改造前完全一致
