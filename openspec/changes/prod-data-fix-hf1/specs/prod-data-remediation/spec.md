## ADDED Requirements

### Requirement: 整分公司资产全清

生产纠错命令 SHALL 支持任意单据构成下的分公司资产全清：该分公司全部实例档案（及行-实例关联）、全部单据（不论审批状态，含待审批与混行单）、全部台账调整单、全部台账行、关联泛化通知 MUST 在同一事务内同批删除——流水重算源（生效单据 ∪ 调整单）与存储值（台账行）同侧归零，待审批单据本就不参与重算，故无需逐行回退算术。前置 MUST 断言：无以该分公司为调出方（from）的单据（防他司数据耦合）、无盘点任务/明细/核查挂该分公司（节点或台账行）、实例镜像一致；违反即中止零变更。组织节点、员工、部门字典、品目字典、实例发号序列 MUST 保留。

#### Scenario: 三源并存分公司全清

- **WHEN** 某分公司并存实例出生单（含混行）、建账调整单、生效数量采购行与待审批单，命令以 `--apply` 全清
- **THEN** 单据（任意状态）、调整单、台账行、实例、关联通知全部删除，五类计数归零
- **AND** `check_ledger_consistency` 零差异，员工与组织节点保留，他分公司零波及

#### Scenario: 存在调出方单据时拒绝

- **WHEN** 该分公司存在任一 from 方向单据（他司调入本司库存的调拨/领用/回收）
- **THEN** 命令断言失败中止，零变更

#### Scenario: 存在盘点引用时拒绝

- **WHEN** 该分公司存在盘点任务，或盘点明细/核查挂其台账行
- **THEN** 命令断言失败中止，零变更
