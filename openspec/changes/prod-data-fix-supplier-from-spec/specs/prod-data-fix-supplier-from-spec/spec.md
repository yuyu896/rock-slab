# prod-data-fix-supplier-from-spec Specification

## Purpose
一次性数据纠错命令：将错填在出生行「本批规格」里的供应商名称移动到供应商字段，实例档案两列归位；只处理命中记录。

## ADDED Requirements

### Requirement: 规格错填供应商的圈定与搬移
命令 SHALL 按品目类型与规格内容圈定错填行，将本批规格内容移动到行级供应商并清空规格；未命中的记录 SHALL 不被修改。

#### Scenario: 电脑类精确命中
- **WHEN** 行的品目名称含电脑/笔记本，且本批规格精确等于 小熊U租/悟空/易点云/小熊/自购 之一，且行级与单头供应商均为空
- **THEN** --apply 后该行供应商 = 原规格值、本批规格为空

#### Scenario: 手机类包含命中
- **WHEN** 行的品目名称含手机，且本批规格包含 瑞克/华为/自购 任一关键词，且供应商为空
- **THEN** --apply 后该行供应商 = 原规格完整内容、本批规格为空

#### Scenario: 未命中不动
- **WHEN** 规格内容不在名单内，或品目类型不符（如规格为"悟空"但品目是打印机）
- **THEN** 该行不被修改

#### Scenario: 供应商已有值沿用且规格清空
- **WHEN** 命中圈定但行级或单头供应商已有值
- **THEN** 供应商保持既有值不覆盖，本批规格仍被清空

### Requirement: dry-run 与幂等
命令 SHALL 默认 dry-run 仅输出清单与统计；SHALL 支持重复执行且已处理行不再命中。

#### Scenario: 默认 dry-run 不落库
- **WHEN** 不带参数执行
- **THEN** 打印命中清单（单据/品目/规格原值/分类统计），数据库无变化

#### Scenario: 幂等自证
- **WHEN** --apply 后再次执行（任意模式）
- **THEN** 命中数为 0
