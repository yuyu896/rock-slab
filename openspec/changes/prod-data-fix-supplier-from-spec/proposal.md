# 提案：数据纠错——错填在规格里的供应商归位（prod_data_fix_supplier_from_spec）

## Why

员工在采购入库时把供应商填进了「规格」字段，导致实例档案的规格列显示供应商名、供应商列为空。需按品目类型与规格内容精确圈定错填记录，将规格内容移动到供应商字段（出生单据行级），规格清空。**只处理命中的记录，未命中的不动。**

## What Changes

- 新增数据纠错管理命令 `prod_data_fix_supplier_from_spec`（沿用 prod_data_fix_* 先例）：
  - **电脑类**（品目名称含"电脑/笔记本"）：出生行「本批规格」**精确等于** 小熊U租 / 悟空 / 易点云 / 小熊 / 自购 之一 → 规格内容移入该行「供应商」，本批规格清空
  - **手机类**（品目名称含"手机"）：本批规格**包含** 瑞克 / 华为 / 自购 之一 → 同上移入供应商
  - **保护规则**：该行供应商已有值（行级或单头）→ 跳过不改、单独列出待人工确认，不覆盖既有数据
  - `--dry-run`（默认）：只打印将改动的单据行清单与统计；`--apply` 才落库；幂等可重复执行（改后规格为空不再命中）
- 数据层落点：`TransferLine.本批规格 → TransferLine.供应商`——实例档案两列（规格/供应商）均由出生行派生，行级修正后展示自动归位
- 数量/台账零变化（纯字段搬移，不触对账纪律）
