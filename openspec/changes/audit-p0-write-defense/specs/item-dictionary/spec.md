## ADDED Requirements

### Requirement: 管理方式切换须无存量

品目「管理方式」（`management_type`）在满足任一存量条件时 MUST NOT 允许变更：挂有实例档案（FixedAsset 引用）或台账任一数量列非零（在库/在用/回收库 > 0）。拒绝时 MUST 返回 400 并说明存量状况与解锁路径（存量清零/实例处置后可切换）；品目序列化输出 MUST 含派生只读标志 `management_locked`（同一判定），供编辑界面禁用切换控件。管理方式为品目固有属性（设计书决策 #2），存量存在期间的两个方向（数量↔实例）均受此约束——反向切换会立即造成实例镜像与台账不一致、阻塞对账。

#### Scenario: 挂有实例的品目改回数量管理被拒

- **WHEN** 管理员编辑实例管理品目 X（挂有 66 条实例档案），把管理方式改为数量管理
- **THEN** 返回 400，提示挂有实例档案不可切换及解锁路径，管理方式不变

#### Scenario: 台账存量非零的品目改为实例管理被拒

- **WHEN** 管理员编辑数量管理品目 Y（在用数量 5、无实例），把管理方式改为实例管理
- **THEN** 返回 400，提示台账存量非零不可切换，管理方式不变，对账不受影响

#### Scenario: 无存量品目可切换管理方式

- **WHEN** 管理员编辑品目 Z（无实例档案、台账三列均为 0），切换管理方式
- **THEN** 保存成功，`management_locked` 为 false
