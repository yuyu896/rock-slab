# asset-batch-import 增量

## ADDED Requirements

### Requirement: 导入表头守卫

批量导入 MUST 校验文件首行表头与该类型期望表头（TYPE_TEMPLATES）**集合一致**：缺失期望列或存在未知列即整体 400，提示「模板已更新，请重新下载」（不进入行级解析）——旧版模板（列集不符）从入口拒绝，杜绝错位乱数据。表头守卫覆盖采购/领用/调拨/回收全部导入类型。

#### Scenario: 旧模板被拒

- **WHEN** 用户上传旧 12 列采购模板（含 物品名称/总金额/采购经办人 列）
- **THEN** 返回 400 提示重新下载模板，零数据入库

#### Scenario: 新模板正常

- **WHEN** 上传当前 9 列采购模板
- **THEN** 表头校验通过，进入行级解析

### Requirement: 合单分组键去备注

采购合单分组键 MUST 为 `日期+分公司+供应商+需求部门`（不含备注），领用为 `日期+分公司+用途`（不含备注）——同键多行必合一张单；备注取组内首行值。表头守卫+键瘦身后，两行同批数据 MUST 生成一张采购单（不再受备注差异/旧模板错位拆单）。

#### Scenario: 备注不同仍合单

- **WHEN** 两行同日期/分公司/供应商/部门，一行备注空一行有字
- **THEN** 合并一张单（备注取首行），两张拆单不再出现
