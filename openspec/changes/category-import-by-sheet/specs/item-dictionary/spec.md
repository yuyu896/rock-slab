# item-dictionary 增量

## ADDED Requirements

### Requirement: 品目 Excel 导入按 sheet 名定管理方式
品目 Excel 导入 SHALL 遍历工作簿全部工作表：表名精确匹配「数量管理」「实例管理」「消耗品」之一的，该表全部行 MUST 按对应管理方式（quantity/instance/consumable）导入；一次上传可同时导入多张命中表。整簿无任何命中表名时 MUST 回退为读取 active sheet 按「数量管理」导入（兼容既有单 sheet 文件），且结果信息 MUST 明示该回退。导入按资产编号幂等（update_or_create）；更新已存在品目且管理方式发生变化时，若该品目挂有实例档案或台账任一数量列非零（复用管理方式存量判定），该行 MUST 计入错误跳过，不得绕过存量守卫。导入结果 MUST 按工作表分组返回（表名、管理方式、导入条数、行级错误）并列出未命中的表名。行数上限按全部命中表行数合计执行。导入模板 MUST 为三张工作表（数量管理/实例管理/消耗品）各带同一七列表头。

#### Scenario: 三表同文件一次导入
- **WHEN** 用户上传含「数量管理」「实例管理」「消耗品」三张表的 xlsx（行数合计 405）
- **THEN** 三张表全部导入，各表行落到对应管理方式，结果按表分组返回条数

#### Scenario: 表名决定管理方式
- **WHEN** 「消耗品」表内某行编号 B-b00001（表内无管理方式列）
- **THEN** 该品目以 management_type=consumable 入库

#### Scenario: 无命中表名回退兼容
- **WHEN** 用户上传旧单 sheet 文件（表名「资产分类」，7 列契约）
- **THEN** 按 active sheet 以数量管理导入，结果信息明示未识别命中表名并已回退

#### Scenario: 存量品目改管理方式被拒
- **WHEN** 导入行编号已存在、目标管理方式不同、且该品目台账在用数量 5
- **THEN** 该行计入错误跳过（提示存量锁定），其余行正常导入

#### Scenario: 命名错误的表被列出
- **WHEN** 工作簿含未命中表名的「Sheet1」（不在三表名内）
- **THEN** 该表不导入，结果 skipped 清单列出「Sheet1」
