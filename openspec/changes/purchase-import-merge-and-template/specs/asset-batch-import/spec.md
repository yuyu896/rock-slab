# asset-batch-import 增量

## ADDED Requirements

### Requirement: 采购/领用导入合单与模板瘦身

采购批量导入 MUST 按单头键（日期+分公司+供应商+需求部门+备注）把相同行合并为**一张采购单**（多明细行、一张单一个单据编号）；领用按（日期+分公司+用途+备注）同构合并。行级校验错误 MUST 仍按行报错跳过（同组其余合法行正常入单）。采购模板 MUST 收敛为 9 列：采购日期/分公司/资产编号/规格型号/供应商/采购数量/单价/需求部门/备注——物品名称由资产编号联字典自动回填、总金额=数量×单价自动计算（模板不含该列）、采购经办人=导入操作人（模板不含）。领用模板 MUST 删除「领用物品」名称列（资产编号联字典）。

#### Scenario: 两行合一张采购单

- **WHEN** 导入文件两行（同日期/同分公司/同供应商，不同资产编号各 10、5 个）
- **THEN** 生成一张采购单（2 条明细行），单据编号一个；台账两品目各入在库

#### Scenario: 不同单头键分单

- **WHEN** 文件含 A 公司与 B 公司的采购行各若干
- **THEN** 生成两张采购单（按单头键分组），各自编号

#### Scenario: 行级错误不拖垮同组

- **WHEN** 合并组内一行资产编号不在字典、其余行合法
- **THEN** 错误行计入 errors 跳过，其余行仍生成该组采购单

#### Scenario: 名称回填与金额自动算

- **WHEN** 合法行导入（模板无名称/金额列）
- **THEN** 明细行品目经字典联查回显名称；金额=数量×单价自动落账；单头采购经办人=操作人姓名
