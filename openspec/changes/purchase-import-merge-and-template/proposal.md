# 采购/领用批量导入合单 + 采购模板瘦身

## Why

采购批量导入当前**一行 = 一张单**：两行数据生成两张采购单，与页面建单「一张单多明细行」的形态相悖，单据数虚胖。采购模板冗余：物品名称可按资产编号从字典取、总金额可由数量×单价算、采购经办人应是谁导入谁是（模板填三列多余；图片列已于 `8778327` 删除）。领用导入存在同款问题（一行一单 + 「领用物品」名称列冗余）。

## What Changes

- **合单**：采购导入按 `日期+分公司+供应商+需求部门+备注` 相同的行合并为一张采购单（多明细行）；领用按 `日期+分公司+用途+备注` 合并。行级校验错误仍按行报错跳过（组内合法行正常入单）
- **采购模板瘦身**（12 列 → 9 列）：`采购日期｜分公司｜资产编号｜规格型号｜供应商｜采购数量｜单价｜需求部门｜备注`——删 物品名称（字典自动）、总金额（数量×单价自动计算，手填值忽略）、采购经办人（=导入操作人）
- **领用模板瘦身**：删「领用物品」名称列（字典自动）
- 导入解析列索引同步；单据编号每组一张
- 非目标：调拨导入维持现状（一行一单，用户未提出）；回收导入已下线不动；模板下载/导出 Excel 的表头同步（导出列含名称/金额为**回显**，不改）
