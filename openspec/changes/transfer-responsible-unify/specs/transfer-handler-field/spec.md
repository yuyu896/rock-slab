## MODIFIED Requirements

### Requirement: 四类流转单据经办人字段统一

采购入库、领用、调拨、回收四类流转单据 SHALL 共用单头字段「经办人」（Transfer 模型字段名 `经办人`，由 `采购经办人` 重命名而来）；字段 MUST 保持文本、选填、可修改语义。创建单据时若未提交经办人（空值），服务端 SHALL 统一回填为创建人姓名（`request.user.name or phone`）——覆盖 Web 表单、移动端提交、归还 API 与**批量导入路径**等全部建单入口；表单路径回填收口在 `_create_action`，导入路径在导入 header 拼装处显式赋值（经办人=导入操作人）。

#### Scenario: 建单不传经办人回填创建人

- **WHEN** 任意客户端（含移动端、归还 API）创建流转单据且未提交经办人
- **THEN** 单据保存后经办人等于创建人姓名

#### Scenario: 显式提交经办人按传入值保存

- **WHEN** 用户在表单中将经办人改为他人姓名后提交
- **THEN** 单据按用户实际输入保存经办人，不被回填覆盖

#### Scenario: 四类创建页预填当前登录人

- **WHEN** 已登录用户打开采购入库/领用/调拨/回收任一创建页
- **THEN** 「经办人」输入框预填当前登录人姓名，可修改、可清空（清空提交后由服务端回填创建人）

#### Scenario: 批量导入经办人为导入操作人

- **WHEN** 用户通过批量导入创建采购或调拨单据（模板不含经办人列）
- **THEN** 导入生成的单据经办人等于导入操作人姓名
