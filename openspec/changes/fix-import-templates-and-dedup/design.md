## Context

- 上次 `simplify-import-templates` 设错列：资产模板误含「供应商」、缺「是否租用」；固定资产模板误删成 7 列。需按用户清单纠正。
- `FixedAsset` 模型现无 物品分类/是否租用/数量/规格/单价/购入金额/出库日期 字段——按决策补字段。
- Asset 同名字段类型：物品分类 CharField(100)、规格 CharField(200)、是否租用 BooleanField(default=False)、数量 IntegerField(default=1)、单价 DecimalField(12,2,null)、购入金额 DecimalField(14,2,null)、出库日期 DateField(null)。
- 两导入均按列名映射（`cell(row, 名称)`）；固定资产导入现按 资产编号 查父资产、继承 分公司/分公司编号/branch。
- 资产导入已有 DB 内重复检查（`资产编号` 全局唯一）；本变更新增**表内**重复检查。

## Goals / Non-Goals

**Goals:**
- 两模板列严格按用户清单（资产 15、固定资产 18）。
- FixedAsset 补字段、导入可存全部列。
- 同表内重复（分公司+资产编号 / 分公司+电脑序列号）提醒。

**Non-Goals:**
- 不改资产模型字段。
- 不改导出列（固定资产导出仍 19 列 `FA_HEADERS`）。
- 不改全局唯一约束（资产编号仍全局唯一；电脑序列号是否加唯一约束见 Open Questions，默认不加、仅表内去重）。

## Decisions

### 决策 1：模板列严格按用户清单
- 资产 15 列、固定资产 18 列（如 proposal 所列）。纠正上次的错误列。

### 决策 2：FixedAsset 补 7 字段（对齐 Asset 类型）
- 新增：物品分类、规格（CharField blank）、是否租用（Boolean default False）、数量（Integer default 1）、单价/购入金额（Decimal null）、出库日期（Date null）。生成迁移。

### 决策 3：固定资产导入按列读取全部 18 列
- 读取分公司/分公司编号/电脑序列号(→序列号)/供应商/物品分类/资产名称/入库日期/是否租用/数量/规格/单价/购入金额/出库日期/所属部门/使用人/当前状态/备注；仍按 资产编号 查父资产（asset FK + 资产名称回退）；分公司/分公司编号/branch 取自文件（分公司编号→Branch 解析 branch FK）。

### 决策 4：表内去重
- 资产导入：维护 `seen={(分公司,资产编号)}`，重复行 → `资产编号 X 重复` 并跳过。
- 固定资产导入：维护 `seen={(分公司,电脑序列号)}`（电脑序列号非空才计入），重复行 → `电脑序列号 X 重复` 并跳过。
- 与既有 DB 重复检查并存（DB 重复仍报「资产编号已存在」）。

## Risks / Trade-offs

- **[模型加字段需迁移]** 部署须 `migrate` → 纳入 deploy.sh（已含 migrate）。
- **[电脑序列号空值]** 空序列号不参与去重（避免多条空值误报）。
- **[固定资产分公司取文件 vs 父资产]** 改为取文件列（用户填写），branch 由分公司编号解析；若与父资产不一致以文件为准。
- **[联合唯一约束 vs 历史数据]** 若线上已存在「同分公司+同序列号(非空)」的重复记录，创建约束的迁移会失败 → **缓解**：部署前先查重清理（实现时给核查命令）；约束用 `condition=~Q(序列号='')` 排除空序列号，降低撞库面。

## Migration Plan

1. 后端：FixedAsset 加字段 + 迁移；两模板表头；两导入去重 + 固定资产读新列。
2. 部署：`bash deploy.sh`（含 migrate）。
3. 前端无需改（模板由后端生成）。
