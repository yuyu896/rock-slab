## ADDED Requirements

### Requirement: 按内部编号点删实例

生产纠错命令 SHALL 支持按内部编号清单删除指定实例档案（多实例行场景）：删除目标实例及其行-实例关联，并将各出生行的数量减去该行被删实例数，台账对应列同额直减——流水重算、存储值、实例镜像三处同步，如同该批少购入了被删数量。前置 MUST 断言：目标全部存在且属于目标分公司、状态为在库、出生单为生效采购单、各涉行数量等于该行出生实例数（行账一致）、品目级镜像一致。实例发号序列 MUST 保留（空号不回收）。

#### Scenario: 多实例行点删部分实例

- **WHEN** 某分公司两条多实例行（×6 与 ×13）中有 3 个指定实例被点删
- **THEN** 3 个实例及关联删除，两行数量变为 4 与 12，台账在库同减 3
- **AND** 同行其余实例与其他单据行原样，`check_ledger_consistency` 零差异

#### Scenario: 非在库实例拒绝

- **WHEN** 目标实例状态非在库（存在领用/回收生平）
- **THEN** 命令前置断言失败中止，零变更

#### Scenario: 行账错位拒绝

- **WHEN** 某涉行的数量不等于该行出生实例数（历史已错位）
- **THEN** 命令前置断言失败中止，零变更
