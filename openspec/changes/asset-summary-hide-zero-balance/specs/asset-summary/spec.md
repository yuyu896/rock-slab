## ADDED Requirements

### Requirement: 资产汇总台账隐藏零总量记录
资产汇总台账页面及其 Excel 导出 MUST 排除在库数量、在用数量和回收库数量均为 0 的台账行。任一数量列大于 0 的行 MUST 保留。此规则 MUST 仅作用于资产汇总台账页面及其导出，不得改变其他调用方使用资产汇总接口时的默认结果；隐藏记录 MUST 保留在数据库中，且不得改变关联库存流水或历史单据。

#### Scenario: 台账列表隐藏三项数量均为零的记录
- **WHEN** 资产汇总台账列表查询包含一条在库、在用和回收库数量均为 0 的记录
- **THEN** 列表结果不包含该记录，分页总数和序号按过滤后的结果计算

#### Scenario: 在用或回收库仍有数量时保留记录
- **WHEN** 一条台账记录的在库数量为 0，但在用数量或回收库数量大于 0
- **THEN** 该记录仍显示在资产汇总台账列表中

#### Scenario: 导出与台账列表使用相同的零总量规则
- **WHEN** 用户导出资产汇总台账，且查询范围内同时存在零总量记录与有数量记录
- **THEN** 导出文件排除三项数量均为 0 的记录，保留有数量的记录，并遵循当前分公司、类目和关键词筛选

#### Scenario: 其他资产汇总接口调用方保持默认结果
- **WHEN** 物品选择器、移动端或其他业务流程调用资产汇总接口且未请求零总量过滤
- **THEN** 接口继续按原有默认规则返回结果，不因台账页面的展示规则额外过滤记录

#### Scenario: 隐藏不改变持久化记录和历史
- **WHEN** 一条零总量台账记录因列表或导出查询规则被隐藏
- **THEN** 数据库中的台账记录、关联库存流水及历史单据保持不变
