# 设计：存量实例状态归一（补丁）

## Context

P2 第二刀迁移 0017 只映射了「空闲→回收库」；体检暴露生产还混有旧 Asset 枚举值（使用中 496）、变体（空闲中 168）等非法状态。用户决断路线 A：品目维持数量管理，档案仅修展示层。

## Goals / Non-Goals

**Goals:** 非法枚举归一为四态，恢复实例列表筛选/状态列展示；写操作收敛 services（架构白名单不破）。
**Non-Goals:** 不动分公司错位（452 条，历史死档语义下无必要）；不动台账；不生成单据；不迁移品目管理方式。

## Decisions

### D1 同义映射表

使用中→在用（旧 Asset 枚举同义）；空闲/空闲中→回收库（回收入库待再分配，与 0017 的 空闲→回收库 一致）；维修中→在用（沿用 P1 台账桶规则：维修中计入在用）；已报废→退役（出局终态，档案保留）。

### D2 只动状态列、命令壳 + services 实现

归一属实例写操作，按铁律收敛 `services/instances.py`（架构测试白名单仅 services/migrations/tests）；命令只做 IO。预览/--confirm 两段式与 align_ledger_to_instances 风格一致。

## Risks / Trade-offs

- [映射语义判断错误] → 映射表全同义、无信息损失；预览先核对条数；退役/回收库为可逆状态（后续单据可再迁移）
