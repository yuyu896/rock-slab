# fixed-asset-table-columns 增量

## ADDED Requirements

### Requirement: 单台编辑页统一保存责任人交接

持有 `manage_instances` 权限的用户 MUST 能在单台实例编辑页查看和编辑在用实例的使用人及部门。使用人 MUST 支持自由文本，部门 MUST 从完整部门字典选择。非在用实例 MUST 只读展示现有责任人。

底部「保存」MUST 先保存普通档案字段，成功后才提交实际有变化的交接字段。界面 MUST 只提供一个保存入口，不得要求额外确认，也不得在批量操作菜单提供交接。普通档案保存失败时 MUST NOT 提交交接；交接失败时 MUST 保留表单输入并提示档案可能已保存，以便重试。

生平 MUST 与编辑表单在同一扩宽弹窗中显示并保留原五列布局。交接行的单据列显示 `-`，类型显示「使用人变更」，使用人列只显示新使用人和新部门，日期只显示年月日。

#### Scenario: 点击保存完成单台交接

- **WHEN** 用户在在用实例编辑页修改使用人或部门并点击「保存」
- **THEN** 系统先保存档案，再提交交接接口；生平显示新事件，且不要求额外确认

#### Scenario: 档案保存成功但交接失败

- **WHEN** 普通档案字段已保存而专用交接接口失败
- **THEN** 编辑弹窗和交接输入值保留，用户得到明确提示，可再次点击「保存」重试
