# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 单台在用实例使用人交接留痕

系统 SHALL 提供单实例使用人和部门交接操作。使用人允许为不在员工账号中的自由文本，部门 MUST 来自部门字典。操作 MUST 原子地更新当前值并追加交接历史，历史包含变更前后使用人和部门名称、操作人快照、时间及可选原因。

交接 MUST 只允许在用实例，且目标实例未被草稿或待审批流转单占用。重复提交相同使用人和部门 MUST NOT 生成新历史。交接 MUST NOT 改变实例状态、所属分公司或台账数量。

实例生平 MUST 将交接历史与流转记录按发生时间倒序合并。交接行 MUST 显示为独立的「使用人变更」事件。

#### Scenario: 成功更换使用人和部门

- **WHEN** 有权限的用户为未被占用的在用实例提交新使用人和有效部门
- **THEN** 当前档案更新，追加含前后快照的历史事件，生平显示该事件，库存数量保持不变

#### Scenario: 交接被单据占用或实例非在用

- **WHEN** 实例处于非在用状态，或被草稿、待审批流转单占用
- **THEN** 系统拒绝交接且不修改当前档案或历史

#### Scenario: 未发生实际变化

- **WHEN** 提交的使用人和部门与实例当前值相同
- **THEN** 系统不追加交接历史
