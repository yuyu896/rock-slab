# fixed-asset-table-columns 增量

## ADDED Requirements

### Requirement: 实例行分割线同高对齐

实例表任意行内全部单元格（含操作列）的下边框 MUST 同高对齐，构成连续的水平行分割线；任何 `<td>` MUST NOT 使用破坏表格单元格布局的 `display` 值（如 `flex`/`block`）——单元格内容排布 SHALL 在单元格内以行内元素或内层容器实现。行因图片缩略图等高内容变高时，操作列等矮内容单元格 MUST 随行伸展并保持垂直居中。

#### Scenario: 挂图行分割线连续

- **WHEN** 某行挂 40px 物品图片使行高增至约 64px
- **THEN** 该行操作列单元格与数据单元格的下边框同高对齐，行分割线视觉连续无错位

#### Scenario: 操作按钮行内排布不变

- **WHEN** 渲染操作列（物品图片/补录/生平/打印标签按钮）
- **THEN** 按钮水平排列、间距与尺寸同既有口径，垂直居中于单元格

### Requirement: 图片弹窗成功即关

实例图片弹窗在上传（含更换）成功或删除成功后 MUST 自动关闭；成功提示与列表缩略图就地更新行为保持不变。删除前的二次确认保持。弹窗内 MUST NOT 因操作失败而关闭（失败停留供重试）。

#### Scenario: 上传成功自动关闭

- **WHEN** 用户在图片弹窗上传（或更换）图片成功
- **THEN** 弹窗自动关闭，行内缩略图已更新并出现成功提示

#### Scenario: 删除成功自动关闭

- **WHEN** 用户确认删除后删除成功
- **THEN** 弹窗自动关闭，行内图片列回到占位标识

#### Scenario: 失败停留可重试

- **WHEN** 上传请求失败（如超限被拒）
- **THEN** 弹窗保持打开，展示错误提示，可重新选择文件
