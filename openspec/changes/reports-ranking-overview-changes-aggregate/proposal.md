# 报表三修——排行降序 / 总览状态表 / 变动按品目聚合

## Why

① 分公司资产排行切「价值」时不降序（后端固定按在库数量序，前端切指标未重排）；② 资产总览被去掉底表后无报表（用户要的是总览专属报表而非与分公司明细重复）；③ 变动明细按单据行铺开过长，需求是按资产（品目）看变动汇总。

## What Changes

- **排行降序**：前端切「数量/价值」时按当前指标重排 branchStats（computed 排序，后端不动）
- **总览状态汇总表**：总览底部新增「资产状态汇总」表——在库/在用/回收库/总量/占比（by-status 接口同源，Excel 式朴素表，容器定高内部滚动）
- **变动明细改资产聚合**：新后端接口按品目聚合期间变动（品目编号/名称/单位 + 入库/领用/调拨/回收/归还 各类合计数量），前端「变动明细」tab 换为该聚合表（保留时间范围筛选与导出）；单据级明细不再在报表展示（单据列表/详情已有）
- 非目标：导出列随新表同步；其他 tab 不动

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `report-metrics`: 排行降序 + 总览状态汇总表 + 变动按品目聚合

## Impact

- **后端**: reports 新聚合端点（按品目×动作类型聚合生效单据行，时间范围过滤）
- **前端**: Reports.vue（排序 computed、总览状态表、变动 tab 换聚合表）
