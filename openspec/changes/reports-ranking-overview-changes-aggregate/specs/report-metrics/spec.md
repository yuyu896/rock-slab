# report-metrics 增量

## ADDED Requirements

### Requirement: 排行按当前指标降序

分公司资产排行的「数量/价值」切换 MUST 使列表按当前所选指标**降序**重排（数量=总量、价值=采购金额），排行名次随切换即时更新。

#### Scenario: 价值降序

- **WHEN** 用户切到「价值」tab
- **THEN** 排行按采购金额从高到低，第 1 名为金额最大者

### Requirement: 资产总览状态汇总表

资产总览底部 SHALL 呈现「资产状态汇总」表：在库/在用/回收库各行（数量+占比），容器定高内部滚动——总览 tab 有自己的报表且不与分公司明细重复。

#### Scenario: 状态表展示

- **WHEN** 用户切到「资产总览」tab
- **THEN** 指标卡+图表之下有状态汇总表（在库 X 台占 N%…）

### Requirement: 变动明细按品目聚合

「变动明细」tab SHALL 展示按**品目聚合**的期间变动表：每品目一行（编号/名称/单位 + 采购入库/领用/归还/调拨/回收合计数量），遵循时间范围筛选；MUST NOT 逐单据行铺开。导出列与表格一致。

#### Scenario: 品目聚合

- **WHEN** 期间品目 X 发生采购 10、领用 3、回收 1（散布在多张单据）
- **THEN** 变动表 X 一行：入库 10｜领用 3｜回收 1（无单据行）
