# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 实例级供应商覆盖与隔离修改

FixedAsset SHALL 支持可选 `供应商` 字段（个体覆盖）。实例供应商派生 MUST 为三级链：`实例.供应商 → 出生行.供应商 → 出生单头.供应商`（先命中先出）。批量维护端点的供应商修改 MUST 写**实例自身字段**且 MUST NOT 触碰出生行——勾选实例之外的同批实例（共享出生行）供应商 MUST NOT 变化。

#### Scenario: 勾选改不影响同行

- **WHEN** 某采购行 81 台实例共享出生行，用户仅勾选 1 台批量设供应商=联想
- **THEN** 该台实例供应商=联想（实例字段）；其余 80 台派生结果不变

#### Scenario: 三级派生

- **WHEN** 实例无自身供应商、出生行供应商=华为、单头=戴尔
- **THEN** 实例显示华为；出生行也空时显示戴尔

#### Scenario: 实例覆盖优先

- **WHEN** 实例自身供应商=联想、出生行=华为
- **THEN** 实例显示联想
