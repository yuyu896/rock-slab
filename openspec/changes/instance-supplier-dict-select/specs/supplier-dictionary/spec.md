# supplier-dictionary 增量

## ADDED Requirements

### Requirement: 实例档案供应商只准选

实例档案的供应商编辑入口（行编辑弹窗、批量修改供应商）SHALL 以供应商字典下拉呈现，仅允许选择字典项或「继承出生单」空值（清空个体覆盖、回落 实例→出生日批次→出生单头 派生链）；MUST NOT 提供自由文本输入。存量单据展示与批量导入的供应商文本 MUST NOT 被强校验拦截。

#### Scenario: 行编辑选择字典供应商

- **WHEN** 用户在实例行编辑弹窗展开供应商下拉
- **THEN** 列出全集团供应商字典项与「继承出生单」首项，选中后保存对应名称

#### Scenario: 清空覆盖回落派生

- **WHEN** 用户将供应商设为「继承出生单」并保存
- **THEN** 实例个体覆盖清空，展示值回落至出生明细行/出生单头供应商（可能为空）

#### Scenario: 批量修改同样收口

- **WHEN** 用户使用批量修改供应商功能
- **THEN** 值来源为字典下拉（含设为继承），确认文案明示影响行数与回落语义

#### Scenario: 存量与导入不受阻（回归）

- **WHEN** 查看历史实例（含非字典值）或经既有导入通道写入
- **THEN** 展示与导入行为与本变更前一致
