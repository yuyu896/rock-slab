## Context

供应商字典上次只收口采购行编辑器（TransferLinesEditor），实例档案两处输入漏网（行编辑弹窗/批量修改弹窗）。实例.供应商 是**个体覆盖**字段：序列化三级链 实例自身 → 出生日.批次供应商 → 出生单头.供应商（serializers.py:101），留空即继承派生——这是"禁止手输"之外必须保留的合法空值语义。

## Goals / Non-Goals

**Goals:**
- 实例档案全部供应商编辑入口只准从字典选取
- 保留「继承出生单」空值语义（清空覆盖）
- （可选，用户拍板）存量别名归一，止住历史脏值

**Non-Goals:**
- 不做 API 强校验（导入/脚本通道沿采购先例保持自由）
- 不给实例加供应商 FK（覆盖快照 + 字典身份源的双层结构与采购行一致）
- 不动出生行/单头的既有数据

## Decisions

| 决定 | 理由 |
|------|------|
| 行编辑下拉首项「继承出生单」（值=空） | 空=回落派生链是既有语义；禁止空会把无出生行的历史档案卡死（无处继承也无处填） |
| 批量修改弹窗同款下拉 + 「设为继承」选项 | 批量清空覆盖影响大，确认文案点名行数；其余同单行语义 |
| 下拉用朴素 `<select>` + 字典选项 | 与行编辑器同款（量少，无需可搜索）；空字典占位不阻断 |
| 存量归一走 prod_data_fix 管理命令（dry-run 默认） | 动生产数据的既定惯例：先预览影响行数再 --apply；映射表内置（小熊系→小熊U租、易点云/瑞克按字典名对齐），后续新增别名改脚本常量 |
| 归一只改实例覆盖值，不动出生行 | 出生行是采购单据（单据纪律：只经单据流变）；实例覆盖值是档案字段可治理 |

## Risks / Trade-offs

- [归一误伤（映射错一家）] → dry-run 报告先行，用户核对行数后才 --apply；映射表保守（只并明确同源别名）
- [无出生行且字典未录该供应商的老档案] → 下拉选不到既有值：保留原值展示不受影响（编辑时如需改，先由 admin 补字典）
- [批量「设为继承」清空后回落到空出生头] → 确认文案明示"将回落至出生单供应商（可能为空）"
- 回归面：前端 vitest + build；实例编辑/批量接口零改动无后端回归
