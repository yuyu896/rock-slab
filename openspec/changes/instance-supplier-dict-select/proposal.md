## Why

供应商字典（supplier-dictionary 变更）只收口了采购建单行编辑器；实例档案的供应商仍为自由文本——行编辑弹窗与批量修改供应商两处可随手输入，导致同一供应商多种写法（生产实测：小熊 / 小熊U租 / 小熊u租 / 小熊U组 四种并存，另有 1723 台在库空值）。实例供应商是未来对账模块圈定租赁设备的关键数据源，必须止住脏值再生。

## What Changes

- 实例档案**行编辑弹窗**：供应商输入改字典**下拉**（getSuppliers 选项），首项为「继承出生单」（空值=清空覆盖、回落三级派生链 实例→出生日批次→出生单头）
- 实例档案**批量修改供应商**弹窗：同样改字典下拉（含「设为继承」清空选项，批量操作确认文案强调影响行数）
- API 层**不强校验**（沿采购先例：导入/脚本通道不受阻）
- **存量归一（用户已确认）**：新增 prod_data_fix 惯例脚本，别名映射合并（小熊/小熊u租/小熊U组→小熊U租 等，生产实测约 664 台），dry-run 默认 + --apply 执行，附影响行数报告
