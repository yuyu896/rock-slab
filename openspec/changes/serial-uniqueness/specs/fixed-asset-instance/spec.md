## MODIFIED Requirements

### Requirement: 序列号补录端点

系统 MUST 提供实例序列号补录端点（PATCH，仅 序列号/备注 两字段），要求 `manage_instances` 操作码；补录 MUST NOT 触碰状态/使用人/分公司（那些经流转单变动）。无权限 MUST 拒绝。补录 MUST 为部分更新语义：仅覆盖请求实际提交的字段，未提交的 序列号/备注 保持原值（显式提交空序列号=有意退回待补录，属合法操作）。提交非空序列号时 MUST 做全局查重（排除自身）：序列号已被其他实例占用 MUST 返回 400（错误挂 `序列号` 字段）且不落库。

系统 SHALL 提供管理命令 `report_serial_duplicates`：分组输出全部非空重复序列号（含分公司/内部编号/状态/使用人）；存在重复时 MUST 以非零退出码结束，无重复时输出成功并以 0 退出。数据库层的非空序列号唯一约束在存量重复清理完成后引入（阶段二，另行变更）。

#### Scenario: 补录序列号

- **WHEN** 持 `manage_instances` 的用户对某待补录实例提交序列号 SN-123
- **THEN** 实例序列号更新为 SN-123，列表待补录标识消失

#### Scenario: 补录重复序列号被拒

- **WHEN** 补录提交的序列号已被其他实例（全局任意分公司）占用
- **THEN** 返回 400（错误信息含该序列号），目标实例不变

#### Scenario: 只补备注不清空序列号

- **WHEN** 对已有序列号 SN-123 的实例仅提交 备注 字段
- **THEN** 备注更新，序列号保持 SN-123

#### Scenario: 补录试图改状态被拒

- **WHEN** 补录请求携带 当前状态 或 使用人 字段
- **THEN** 返回 400，仅 序列号/备注 可修改

#### Scenario: 无权限补录被拒

- **WHEN** 不持 `manage_instances` 的用户调用补录端点
- **THEN** 返回权限不足错误，实例无变化

#### Scenario: 重复报告命令

- **WHEN** 库中存在重复序列号时运行 `python manage.py report_serial_duplicates`
- **THEN** 分组输出全部重复实例明细并以非零退出码结束；清理干净后运行输出成功并以 0 退出
