# list-filter-ux Delta

## ADDED Requirements

### Requirement: 列表筛选与页码路由持久化
PC 列表页的筛选条件与页码 SHALL 持久化到路由 query：筛选变更同步写 query（不产生浏览器历史记录），进入或返回页面时 SHALL 从 query 恢复筛选与页码并重新拉取列表数据（不使用页面缓存，数据始终为最新查询结果）。

#### Scenario: 详情页往返筛选保留
- **WHEN** 用户在某列表页设置筛选（如采购入库列表按状态=待审批）后进入详情页，再返回列表
- **THEN** 列表恢复先前的筛选与页码并重新拉取数据，不重置为默认视图

#### Scenario: 筛选变更同步 query
- **WHEN** 用户变更筛选条件
- **THEN** URL query 即时反映当前筛选（仅含有值的键，空值键移除），且不新增浏览器历史条目（后退不回放筛选变化）

#### Scenario: 带 query 直达筛选视图
- **WHEN** 用户打开带筛选 query 的列表页链接（分享/收藏）
- **THEN** 页面按 query 恢复筛选并展示对应结果

#### Scenario: 恢复不误触发
- **WHEN** 页面带 query 挂载并恢复筛选
- **THEN** 仅执行一次数据拉取，页码不被恢复过程重置

#### Scenario: 手动重置清空 query
- **WHEN** 用户点击「重置」
- **THEN** 筛选归零、query 清空、列表回到默认全量视图

#### Scenario: 脏 query 容错
- **WHEN** query 中存在未知键或无法反序列化的值
- **THEN** 忽略该项并回退对应筛选的默认值，页面不报错

### Requirement: 筛选栏宽度均衡
PC 列表页筛选栏宽度 SHALL 均衡：搜索输入框最大宽度约 400px（窄屏自适应收窄），分公司多选下拉宽度约 300px（可容纳长分公司名与多选标签）；规则 SHALL 统一应用于全部使用该筛选栏结构的列表页与弹窗。

#### Scenario: 宽屏下搜索框不独占
- **WHEN** 列表页在宽屏（如 ≥1400px）下渲染筛选栏
- **THEN** 搜索输入框宽度不超过约 400px，不再独占剩余宽度

#### Scenario: 分公司下拉可容纳长名
- **WHEN** 分公司下拉展示长名称分公司或多选标签
- **THEN** 控件宽度约 300px，内容不拥挤溢出

#### Scenario: 窄屏自适应
- **WHEN** 列表页在窄窗口下渲染
- **THEN** 筛选栏各项随窗口收窄换行或收缩，不溢出容器
