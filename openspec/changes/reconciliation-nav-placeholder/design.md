## Context

对账业务：租赁设备月度供应商账单核对（序列号 join 实例档案），功能本体待五个业务口径（账单格式/范围圈定/差异处理深度/执行者/序列号脏度）明确后专门立项。用户定案：本期只占导航位，页面空白。

## Goals / Non-Goals

**Goals:** 导航有「对账」入口，admin 可点进空白页。

**Non-Goals:** 不做任何业务逻辑/模型/接口；不做空态文案设计（页面按用户要求空白——仅页面标题）。

## Decisions

| 决定 | 理由 |
|------|------|
| 名称「对账」，不带租赁/月度限定 | 对业务实质留扩展空间；探讨会建议值，评审可改 |
| 顶级菜单位置（资产盘点后） | 外部账单核对是独立物种（非盘点变体），功能体量大值得顶级 |
| 占位期 admin 可见 | 对账是行政性工作；避免普通用户见死模块；功能落地时按实际执行者放宽 |
| 页面仅标题留白 | 用户明示「页面先空白」；不做建设中说明文案 |
| 纯新增不触碰既有代码 | router 加一行、侧边栏加条件项、新视图文件——零修改既有逻辑，回归面仅 build |

## Risks / Trade-offs

- [占位期过长成僵尸入口] → 与对账大提案绑定推进；移除成本三项纯新增文件
- [admin-only 与未来执行者不符] → 可见性是条件渲染一行，功能立项时随权限设计调整
