## ADDED Requirements

### Requirement: 实例列表按需加载图片缩略图

实例档案列表 MUST 使用 `缩略图` URL 显示列表图片，并仅在图片接近可视区域时加载。用户打开图片预览时 MUST 使用 `图片` 主图 URL。记录没有缩略图但有主图时，列表 MUST 回退到主图；没有主图时 MUST 显示现有空图片占位。

#### Scenario: 加载列表缩略图
- **WHEN** 带有主图和缩略图的实例进入列表可视区域
- **THEN** 列表请求缩略图 URL，不请求该行的主图 URL

#### Scenario: 点击缩略图预览主图
- **WHEN** 用户点击一条有主图的实例列表图片
- **THEN** 图片预览加载该实例的 `图片` 主图 URL

#### Scenario: 旧图片缩略图尚未回填
- **WHEN** 实例有主图但 `缩略图` 字段为空
- **THEN** 列表继续显示主图，不显示破损图片图标

#### Scenario: 实例没有图片
- **WHEN** 实例没有主图和缩略图
- **THEN** 列表显示现有空图片占位且不发起媒体请求
