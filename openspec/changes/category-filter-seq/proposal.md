# 品目页筛选与序号

## Why

品目字典已按管理方式（数量管理/实例管理/消耗品）三分，但品目页没有按管理方式筛选的入口，用户在几百条品目里找"所有消耗品"只能肉眼扫表格；同时品目表格没有序号列，与台账页等其他列表页不一致，翻页后难以对行沟通（"第 37 行那条"无从说起）。

## What Changes

- 品目页筛选栏新增「管理方式」下拉筛选（全部/数量管理/实例管理/消耗品），与既有 筼产类目、物品分类、关键词 筛选并联，由后端分页接口执行筛选
- 品目表格视图新增「序号」列，采用系统既有分页连续序号逻辑（`(page-1) × pageSize + index + 1`，与资产台账页一致）；卡片视图同步显示序号
- 品目页「导出」参数与筛选栏对齐：现状只透传 资产类目+关键词，补齐 物品分类+管理方式（属既有导出遵循筛选总则的一致性修补）

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `item-dictionary`: 新增需求「品目列表筛选与序号」——列表接口支持管理方式筛选参数；列表页提供管理方式筛选控件；表格序号列采用分页连续序号
- `export-filter-alignment`: 品目导出参数从「资产类目+关键词」扩为「资产类目+物品分类+管理方式+关键词」全量透传

## Impact

- 后端：`backend/apps/categories/filters.py`（CategoryFilterSet 增管理方式过滤参数，沿用中文参数名惯例）
- 前端：`frontend/src/views/Category.vue`（筛选下拉、序号列/角标、导出参数、watch 联动）
- 测试：后端 filters 回归；前端 vitest（品目页表头/序号连续性）+ `npm run build` 类型门
- 不动模型、不动台账、不动权限——纯列表页表现层与查询参数，无铁律冲突
