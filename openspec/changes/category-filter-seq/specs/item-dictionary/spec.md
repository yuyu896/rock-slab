# item-dictionary 增量

## ADDED Requirements

### Requirement: 品目列表筛选与序号
品目列表接口 SHALL 支持按管理方式筛选（参数名沿用中文惯例「管理方式」，取值 quantity/instance/consumable，精确匹配），与既有的资产类目、物品分类、关键词筛选可任意组合；品目页筛选栏 MUST 提供管理方式下拉（全部/数量管理/实例管理/消耗品，选项值取管理方式枚举键）。品目表格视图 MUST 在首列展示序号，序号 MUST 为分页连续序号（(页码−1) × 每页条数 + 行序 + 1，与资产台账页同公式）；卡片视图 MUST 同步展示按同公式计算的序号。

#### Scenario: 按管理方式筛选消耗品
- **WHEN** 用户在品目页管理方式下拉选择「消耗品」
- **THEN** 列表仅显示管理方式为 consumable 的品目，分页总数同步收窄，且筛选参数透传列表接口

#### Scenario: 管理方式与类目组合筛选
- **WHEN** 用户同时选择资产类目「低值易耗品类」与管理方式「消耗品」
- **THEN** 列表仅显示同时满足两条件的品目

#### Scenario: 表格序号分页连续
- **WHEN** 品目表格每页 50 条，用户翻到第 2 页
- **THEN** 该页首行序号为 51，页内依次递增

#### Scenario: 卡片视图显示序号
- **WHEN** 用户切换到卡片视图
- **THEN** 每张品目卡片显示与表格同公式计算的序号
