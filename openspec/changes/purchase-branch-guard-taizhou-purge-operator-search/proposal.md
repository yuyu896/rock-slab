# 采购分公司守卫 + 台州定向清数 + 流转搜经办人

## Why

生产排查：687 张采购单中 624 张无入库分公司——根因是**导入代码把采购模板「分公司」列装进了 `调出分公司`（from_branch）**（方向装反的 bug）：员工分公司列全部填了（from 全有值），入库方 to_branch 恒空。均为待审批未生效，无台账影响。另：19分台州整批资产数据为员工录入错误需定向清除（199 实例/4 台账行/1 张生效采购单，无跨公司引用）。再者：流转列表关键字搜索不覆盖经办人，找「某人经手的单」无从下手。

## What Changes

- **方向修复**：采购导入分公司列改赋 `调入分公司`（to_branch，入库方语义），守卫 label 同步「入库分公司」（空值守卫本就在位）；生产 624 张待审批采购单把 from_branch 值**对调搬到 to_branch**（from 清空、文本同步）——单上员工填的分公司本就正确
- **台州定向清数**：删除 19分台州的 1 张生效采购单（含明细行/实例关联）、199 台实例、4 行台账、台州序列行——一次事务、先备份；对账验证零差异
- **搜经办人**：流转列表关键字搜索（keyword）扩展匹配 `采购经办人`/`创建人`（icontains，与单号/品目搜索并列）；前端搜索框 placeholder 补「经办人」提示
- 非目标：其他分公司数据不动；导入模板列结构不变；回收台账搜索不动（其 keyword 为单据派生行内匹配）

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `asset-batch-import`: 批量导入新增行级守卫——采购分公司列为空拒绝
- `transfer-list-action-buttons`（或流转列表筛选相关能力）: keyword 搜索扩展经办人匹配

## Impact

- **后端**: `transfers/views.py` import 分支（分公司空行级错误）、`filters.py` keyword 加经办人匹配、测试
- **前端**: 各流转列表搜索 placeholder 文案
- **生产运维**: 删 625 张垃圾待审批采购单 + 台州定向清理（备份先行）
