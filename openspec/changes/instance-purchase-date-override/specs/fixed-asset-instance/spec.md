# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 实例采购日期个体覆盖

FixedAsset SHALL 支持可选 `采购日期` 字段（DateField，个体覆盖）。实例采购日期派生 MUST 为两级：`实例.采购日期 → 出生单.调拨日期`。设置个体采购日期时 MUST 同步写实例 `入库日期` 实体列等于新日期（业务规则：入库日期=采购日期）；清除覆盖时入库日期回退出生单调拨日期。编辑弹窗 SHALL 提供「采购日期」日期输入（空=沿用出生单日期）；批量维护端点白名单 MUST 加入 `采购日期`（单值统一设置勾选台，入库日期同步）。修改 MUST NOT 触碰采购单（单据日期与合单结构不动）。

#### Scenario: 编辑弹窗改日期

- **WHEN** 员工在编辑弹窗将某实例采购日期改为 2024-06-15 并保存
- **THEN** 实例档案/生平显示 2024-06-15，入库日期同步为 2024-06-15；出生采购单的调拨日期不变

#### Scenario: 清除覆盖回退

- **WHEN** 清除个体采购日期保存
- **THEN** 采购日期与入库日期均回退出生单调拨日期

#### Scenario: 空值回退出生单

- **WHEN** 实例未设个体采购日期
- **THEN** 显示出生单调拨日期；存量无出生行实例显示空

#### Scenario: 批量统一设日期

- **WHEN** 勾选 3 台实例批量设采购日期=2025-01-01
- **THEN** 三台个体采购日期更新，出生单不动
