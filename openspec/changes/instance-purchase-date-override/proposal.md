# 实例采购日期个体覆盖

## Why

系统切换期采购入库单是存量导入的过渡载体（导完将全删），但导入行的采购日期常有错误。采购日期现从出生采购单「调拨日期」派生且为合单分组键——改单据会连带整单并破坏"一行一日期归单"结构。实例级覆盖（同规格/供应商模式）让员工逐台修正实际采购日期，单据零触碰；单据删除后个体日期即唯一事实源。

## What Changes

- `FixedAsset` 加可选 `采购日期` 字段（DateField，个体覆盖）；实例采购日期派生改两级：**实例.采购日期 → 出生单.调拨日期**
- **入库日期同步**（业务规则：入库日期=采购日期）：设置个体采购日期时同步写实例 `入库日期` 实体列（清除覆盖时回退出生单日期）
- 编辑弹窗左栏加「采购日期」日期输入（空=沿用出生单日期）；保存随 batch-update 提交
- batch-update 白名单加 `采购日期`（单值：勾选台统一设置，编辑弹窗单台场景天然精确）
- 非目标：不改采购单/合单逻辑；不改报表时间口径（报表按单据日期，过渡期不依赖）；台账/生平展示沿用派生值自动生效
