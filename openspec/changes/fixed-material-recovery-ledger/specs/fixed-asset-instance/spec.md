## ADDED Requirements

### Requirement: 普通实例档案排除已直接处置实例

普通实例档案列表 MUST 排除已关联已生效直接处置回收明细的实例。排除判断 MUST 基于生效的直接处置单据事实，不得仅因实例状态为“退役”而排除。实例档案记录、内部编号及历史单据关联 MUST 保留，并可从物资处置台账只读查询。

#### Scenario: 生效直接处置实例从普通列表移出

- **WHEN** 某实例关联一条已生效的直接处置回收明细
- **THEN** 该实例不出现在普通实例档案列表中，但仍可从物资处置台账查看其档案及生平

#### Scenario: 其他退役原因不触发排除

- **WHEN** 某实例状态为退役，但没有已生效的直接处置回收明细
- **THEN** 该实例仍按原有规则出现在普通实例档案查询结果中

#### Scenario: 未生效处置不触发排除

- **WHEN** 某实例关联的直接处置单据待审批或已驳回
- **THEN** 该实例不因该单据从普通实例档案列表中排除
