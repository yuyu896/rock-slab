## ADDED Requirements

### Requirement: 按内部编号修正入库日期

生产纠错命令 SHALL 支持按内部编号清单逐实例修正 `入库日期`（记录性快照字段）：仅更新值不同的实例（幂等），出生单据日期与其余字段 MUST NOT 变动，台账数量与镜像 MUST NOT 受影响。前置 MUST 断言目标实例全部存在且属于目标分公司，缺失即中止零变更。

#### Scenario: 逐实例修正采购日期

- **WHEN** 命令以 `--apply` 按常量表修正某分公司 7 个实例的入库日期
- **THEN** 各实例入库日期更新为对应新值（现值相同者跳过），出生单据日期不变
- **AND** 台账与实例镜像零变化，`check_ledger_consistency` 零差异

#### Scenario: 目标缺失即中止

- **WHEN** 常量表中任一内部编号不存在（或不在目标分公司）
- **THEN** 命令前置断言失败中止，全部零变更
