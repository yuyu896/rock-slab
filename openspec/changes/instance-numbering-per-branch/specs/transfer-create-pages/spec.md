# transfer-create-pages 增量

## ADDED Requirements

### Requirement: 领用行实例单台选择

领用出库明细行的实例选择 MUST 为**单台**模式：一行 = 一个使用人 = 一台实例，行数量恒 1（锁定不可改），选中即定（无多选勾选）；需要领多台或多使用人时 SHALL 增加明细行（每行各自的使用人与实例）。调拨/归还/回收行的实例选择 MUST 维持多选形态不变。后端「实例数=数量」矩阵校验保持（领用行恒 1 台=数量 1）。

#### Scenario: 一行一使用人一实例

- **WHEN** 用户在领用行选择使用人张三并点选实例 X-JH002-3
- **THEN** 该行实例确定为 X-JH002-3、数量锁定为 1；再点其他实例为换选而非追加

#### Scenario: 多人多台走多行

- **WHEN** 张三领 2 台、李四领 1 台同品目
- **THEN** 用户建 3 行明细（张三两行各选一台、李四一行一台），提交校验通过
