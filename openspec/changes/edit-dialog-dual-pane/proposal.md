# 编辑弹窗双栏（编辑+生平）与图片区放大

## Why

上案编辑归一的三个体验问题：① 编辑按钮图标仍是相机（旧图片按钮图标未换铅笔）；② 编辑弹窗内图片预览区过小；③ 生平独立按钮+抽屉与编辑弹窗分离——查看生平与改档案是同一场景（核对这台机器的来历再改），应合为一处。

## What Changes

- 编辑按钮图标换**铅笔**；操作列收敛为 **编辑 / 打印标签** 两个按钮（生平并入编辑弹窗）
- 编辑弹窗改**双栏**（加宽至 ~960px）：左栏 = 编辑表单（序列号/备注/规格/供应商 + 图片区**放大**——预览 120px、弹窗内独立滚动）；右栏 = **实例生平**（打开时拉取 timeline：出生信息 + 流水表，沿用现生平抽屉内容结构，独立滚动）
- 生平独立抽屉与行按钮退役（数据端点复用 getFixedAssetTimeline）
- 移动端降级：双栏改上下堆叠（媒体查询）
- 非目标：生平数据结构不动；编辑保存逻辑不动（batch-update 四项+图片即时）

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `fixed-asset-instance`: 编辑弹窗双栏布局（编辑+生平）、图片区放大、操作列两按钮

## Impact

- **前端**: 仅 `FixedAssetList.vue`（图标、弹窗布局、生平并入、样式）；vitest 适配
- **部署**：完工停本地，用户本地验证后自行部署
