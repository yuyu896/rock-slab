# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 编辑弹窗双栏布局

实例「编辑」弹窗 SHALL 为双栏（宽 ≥920px，窄屏堆叠降级）：**左栏编辑**（上下文 + 序列号/备注/规格/供应商 + 图片区）、**右栏实例生平**（打开时拉取 timeline：出生信息 + 全部流转流水倒序，独立滚动）。操作列 SHALL 收敛为 **编辑 / 打印标签** 两个按钮（编辑按钮用铅笔图标）；生平独立入口与抽屉退役。图片区 SHALL 放大（预览 ≥120px，上传/更换/删除操作不变、即时生效弹窗保持打开）。

#### Scenario: 双栏编辑

- **WHEN** 用户点击某行「编辑」（铅笔图标）
- **THEN** 弹窗左栏为编辑表单（图片预览放大），右栏展示该实例生平（出生信息+流水）可滚动

#### Scenario: 生平并入

- **WHEN** 用户在编辑弹窗右栏核对生平后在左栏修改规格并保存
- **THEN** 保存成功弹窗关闭，列表规格列更新——查看与修改一处完成

#### Scenario: 窄屏堆叠

- **WHEN** 浏览器宽度 <768px 打开编辑弹窗
- **THEN** 双栏上下堆叠（编辑在上、生平在下），各自可滚动
