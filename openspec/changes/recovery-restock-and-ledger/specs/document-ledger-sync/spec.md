# document-ledger-sync 增量

## MODIFIED Requirements

### Requirement: 回收单去向二选一
回收单 MUST 携带回收去向：**重新入库（默认）**或直接处置；选择直接处置时 MUST 记录处置方式（出售/报废/捐赠），出售 MUST 记录金额。两种去向的在用扣减一致：重新入库在用→在库（回收库列不变）；直接处置在用减少且不进任何库存列（实例转退役，减少量由单据流水解释）。回收去向 MUST NOT 再产生回收库列增量。存量（回收库实例与台账回收库列）MUST 经一次性归一命令并入在库（实例状态回收库→在库、台账经调整单搬家，留痕）。

#### Scenario: 回收重新入库
- **WHEN** 台账行在用 4、在库 1、回收库 0，回收单（数量 3，去向=重新入库）审批通过
- **THEN** 在用 1、在库 4、回收库不变

#### Scenario: 回收直接处置记金额
- **WHEN** 回收单（数量 2，去向=直接处置，方式=出售，金额 500）审批通过
- **THEN** 在用 −2，回收库不变，单据留存处置方式与金额

#### Scenario: 存量回收库归一
- **WHEN** 归一命令在存量（某分公司某品目回收库实例 5、台账回收库 5）上执行
- **THEN** 实例全部转为在库、台账回收库 0→在库 +5（经调整单留痕），对账零差异
