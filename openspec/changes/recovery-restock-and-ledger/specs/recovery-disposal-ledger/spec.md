# recovery-disposal-ledger Specification

## ADDED Requirements

### Requirement: 回收台账界面（处置明细流水）

系统 SHALL 在回收菜单下提供「回收台账」入口（与回收单列表并列，路由 `/transfers/recovery/ledger`）：以**物资明细**为主呈现全部直接处置记录——实例管理品目逐台一行，数量管理品目按明细行一条。每条 MUST 含：日期（单据调拨日期）、单号（溯源引用）、分公司、品目编号、品目名称、规格、数量、内部编号（实例品目）、处置方式、处置金额、经办人、备注。数据源为回收单（回收去向=直接处置）明细行经字典/实例联查派生，MUST NOT 新增存储表（铁律 1：处置经过已在单据）。界面 SHALL 为朴素表格 + 筛选（分公司、日期区间、品目关键字）+ 标准分页 + Excel 导出（列与表头一致）。仅生效（已入库/已通过）单据进入台账。

#### Scenario: 逐台处置流水

- **WHEN** 某回收单（去向=直接处置，出售 500 元）含实例品目 2 台（X-1、X-2）与数量品目 1 行（数量 5）
- **THEN** 回收台账出现 3 条流水：X-1、X-2 各一条（内部编号列填值）+ 数量行一条（数量 5、内部编号空），处置金额/方式取单头

#### Scenario: 筛选与导出

- **WHEN** 管理层按分公司 + 日期区间筛选后导出
- **THEN** Excel 仅含筛选结果，列头与界面表头一致

#### Scenario: 未生效单据不进台账

- **WHEN** 某直接处置回收单仍为待审批
- **THEN** 回收台账不出现其明细
