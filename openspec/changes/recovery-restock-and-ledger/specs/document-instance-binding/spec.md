# document-instance-binding 增量

## MODIFIED Requirements

### Requirement: 明细行实例引用输入矩阵

单据创建/编辑的明细行 MUST 支持携带 `instances`（实例 uuid 数组），并按「品目管理方式 × 单据类型」矩阵校验：

- 实例管理品目 × 领用/归还/调拨/回收：MUST 携带实例，且 `len(instances) == 数量`；实例的品目 MUST 与行品目一致
- 实例管理品目 × 采购：MUST NOT 携带实例（实例在生效时自动生成）
- 数量管理品目 × 任意类型：MUST NOT 携带实例（携带即 400）

领用单 MUST 携带库存来源（`领用来源`：stock 新品库，单头级，默认新品库——**回收库来源已退役**，携带 recycle_bin MUST 拒绝）；领用行实例 MUST 为「在库」态且实例分公司等于调出分公司。归还/回收行实例 MUST 为「在用」态；回收（重新入库）生效后实例转「在库」；调拨行实例 MUST 为「在库」态且分公司等于调出分公司。领用行使用人 MUST 非空（实例绑人语义）。

#### Scenario: 领用实例管理品目必须绑实例

- **WHEN** 用户提交领用单，行品目为实例管理且未携带 instances
- **THEN** 返回 400，提示该行必须选择与数量等长的实例

#### Scenario: 实例数量与行数量不符被拒

- **WHEN** 领用行数量 3 但仅携带 2 个实例
- **THEN** 返回 400，提示实例数与数量不一致

#### Scenario: 数量管理品目携带实例被拒

- **WHEN** 某行品目为数量管理但携带 instances
- **THEN** 返回 400，提示数量管理品目无需选择实例

#### Scenario: 领用来源回收库被拒

- **WHEN** 领用单携带 领用来源=recycle_bin
- **THEN** 返回 400，提示回收库来源已退役（领用来源仅支持新品库）

#### Scenario: 回收重新入库实例转在库

- **WHEN** 回收单（去向=重新入库）生效，实例 X 原为在用（使用人张三）
- **THEN** 实例 X 转在库，使用人/部门清空
