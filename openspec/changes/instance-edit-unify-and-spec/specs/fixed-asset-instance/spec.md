# fixed-asset-instance 增量

## ADDED Requirements

### Requirement: 规格个体覆盖与三级派生

FixedAsset SHALL 支持可选 `规格` 字段（个体覆盖）。实例规格派生 MUST 为三级链：`实例.规格 → 出生日.本批规格 → 品目字典.规格`。批量维护端点白名单 MUST 加入 `规格`（写实例自身字段，勾选谁改谁，同行不连带）。

#### Scenario: 个体规格优先

- **WHEN** 实例自身规格='黑色'、出生行本批规格='白色'
- **THEN** 实例显示黑色；自身空时显示本批规格、再空回退字典

#### Scenario: 批量改规格隔离

- **WHEN** 同批 3 台实例勾选 1 台批量设规格
- **THEN** 仅该台实例规格更新，其余 2 台派生结果不变

### Requirement: 行编辑归一

实例档案行操作列 SHALL 收敛为三个按钮：**编辑、生平、打印标签**。「编辑」弹窗 MUST 承载全部行级编辑：序列号、备注、规格（个体覆盖）、供应商（个体覆盖）、物品图片（上传/更换/删除）——单台一站式修正。编辑提交后列表行数据就地刷新。

#### Scenario: 单按钮编辑全项

- **WHEN** 用户点击某行「编辑」
- **THEN** 弹窗含 序列号/备注/规格/供应商 输入与图片上传区，保存后行内相应列更新

### Requirement: 批量修改规格与备注列

批量操作菜单 SHALL 含：打印标签、修改供应商、修改备注、补录序列号、**修改规格**（五项，均 manage_instances 可见）。实例列表 SHALL 显示「备注」列（尾部，空值 -）。

#### Scenario: 批量规格

- **WHEN** 勾选 2 台实例批量设规格='改装版'
- **THEN** 两台实例个体规格更新，列表规格列显示改装版

#### Scenario: 备注列可见

- **WHEN** 某实例备注='屏幕有划痕'
- **THEN** 列表该行备注列显示该文本；空备注显示 -
