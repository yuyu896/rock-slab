# 实例编辑归一 + 规格个体覆盖 + 备注列

## Why

实例档案行操作列四个按钮（物品图片/补录/生平/打印）显拥挤，编辑类功能分散；规格与供应商一样存在个体修正需求（当前规格纯派生：出生行本批规格→品目字典，无法改单台）；员工有备注习惯但列表无备注列。

## What Changes

- **规格个体覆盖**：`FixedAsset` 加可选 `规格` 字段；规格派生改三级链 **实例 → 出生行本批规格 → 品目字典**（与供应商三级链同构）；批量维护端点白名单加 `规格`
- **批量操作**：菜单加「批量修改规格」（写实例个体字段，勾选谁改谁）
- **行操作归一**：操作列收敛为 **编辑 / 生平 / 打印标签** 三个按钮——「编辑」弹窗承载全部行级编辑：序列号、备注、**规格、供应商**（个体覆盖）、物品图片（上传/更换/删除）
- **备注列**：实例列表加「备注」列（现有序列化字段，列表尾部）
- 非目标：状态/使用人/分公司编辑仍经流转单（铁律）；导出列不动（后续按需）

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `fixed-asset-instance`: 规格三级派生 + 编辑归一 + 批量规格 + 备注列展示

## Impact

- **后端**: FixedAsset 加 `规格` 列（migration additive）、item_spec 三级派生、batch-update 白名单加 规格
- **前端**: FixedAssetList（编辑弹窗整合、操作列三按钮、批量菜单五项、备注列）
- **部署**：完工停本地，用户本地验证后自行部署（生产在用）
