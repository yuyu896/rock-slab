# asset-batch-import 增量

## ADDED Requirements

### Requirement: 导入文件防重传

批量导入 MUST 记录上传指纹（文件内容 SHA-1 × 上传者），同一指纹在 24 小时内再次上传 MUST 整体 400 拒绝（提示「该文件刚已导入过，请勿重复上传；如需重新导入请修改文件内容」）——防止同一文件手滑多次上传导致的整批重复单据。守卫覆盖采购/领用/调拨/回收全部导入类型，在任何解析/建单之前快速失败。

#### Scenario: 同文件重传被拒

- **WHEN** 用户上传文件 F 成功导入（部分或全部行入库），5 分钟后再次上传同一文件 F
- **THEN** 返回 400 防重传提示，零新单据；其他文件正常

#### Scenario: 修改后的文件放行

- **WHEN** 用户在 F 基础上增改行后（内容变化、指纹不同）再上传
- **THEN** 正常进入解析流程
