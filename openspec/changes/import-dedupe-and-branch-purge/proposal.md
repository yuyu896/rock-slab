# 导入文件级去重 + 三分公司数据清理

## Why

生产实证：北京三分/五分采购导入出现"每条数据复制一条"——同一文件被多次上传（同键 4 张/2 张单），单次上传内合单（26 案）不覆盖跨次重复；"驳回后数据仍入库"实为其孪生症状（驳回一张、重复单另一张被通过入账）。另：32分宁波需保留实例档案清理其余数据；北京三分/五分数据全清重录。

## What Changes

- **文件级去重**：导入端点记录上传指纹（文件内容 SHA1 + 上传者），同一指纹 24 小时内重复上传 → 400「该文件刚已导入过，请勿重复上传」——防手滑重传（四类型导入全覆盖）
- **32分宁波**：保留实例档案（187 台）与台账行；删除采购单 154 张（生效 38 已入账）、旧调整单 34 条；断开实例出生行（置空，生平按存量档案展示）；每台账行补一条**期初调整单**（is_initial=True，吸收全部历史流水，对账文档既有语义）——账实零差异且实例完整保留
- **北京三分/五分**：全口径清理（单据/实例/台账/调整单/序列，同南京杭州口径）
- 非目标：行级内容指纹去重（误杀合法重复行如同品目两批）；驳回流程不改（已核实无缺陷）
