## MODIFIED Requirements

### Requirement: 系统必须支持按业务操作授予管理权限

系统 MUST 提供确认后的业务操作目录，可为员工授予查看、编辑、删除草稿、审批和其他独立操作。业务操作 MUST 只负责对应功能；查看权限 MUST NOT 隐式授予写权限。所有声明了查看前置的操作，授权 API 和运行时接口 MUST 要求全部前置权限。

#### Scenario: 查看权限不授予写权限
- **WHEN** 员工只持有“查看品目”
- **THEN** 员工 MUST 能查看品目
- **AND** MUST NOT 因此新增、编辑、删除或导入品目

#### Scenario: 不满足前置的授权被拒
- **WHEN** 授权 API 请求只授予“编辑采购入库单”而没有“查看采购入库单”或“查看品目”
- **THEN** API MUST 返回 400
- **AND** MUST NOT 保存该权限组合

#### Scenario: 编辑组织节点的集团名称范围
- **WHEN** 非全组织数据范围用户修改集团名称
- **THEN** 请求 MUST 被拒绝
- **AND** 该用户仍可在其授权范围内执行允许的组织节点编辑

### Requirement: 数据范围必须由显式管理授权决定

非 admin 用户的业务数据 MUST 按显式管理范围裁剪；全组织范围只扩大数据可见范围，不自动授予任何业务操作权限。写操作 MUST 校验目标分公司处于当前范围内，盘点锁定期间禁止台账导入和手工调整入账。

#### Scenario: 全组织范围不自动获得审计权限
- **WHEN** 非 admin 用户具有全组织数据范围但没有 `view_audit_logs`
- **THEN** 用户 MUST 不能读取审计日志

#### Scenario: 范围外写操作被拒绝
- **WHEN** 用户对当前数据范围外的流转单、盘点任务、台账或实例执行写操作
- **THEN** 请求 MUST 被拒绝且不得落库

#### Scenario: 盘点锁阻止台账写入
- **WHEN** 分公司存在进行中或锁定状态的盘点任务
- **THEN** 台账导入和手工调整 MUST 被拒绝

### Requirement: 超级管理员必须拥有内置全权

`role == 'admin'` 的系统管理员 MUST 拥有全部业务权限和全组织数据范围，且不依赖授权表记录。管理员权限不可通过普通账号授权接口逐项修改。

#### Scenario: 管理员不需要勾选权限
- **WHEN** 系统管理员访问权限分配或业务页面
- **THEN** 系统 MUST 显示内置全权摘要，不提供逐项撤销控件

### Requirement: 旧权限迁移必须提供可恢复快照

系统 MUST 先生成只读迁移预览，再应用已确认的旧码映射；无法无损映射的旧码 MUST 保留为待核对历史记录。迁移前后权限和范围快照 MUST 可用于恢复。

#### Scenario: 待核对旧权限不扩大
- **WHEN** 旧权限同时覆盖多个新功能但没有明确拆分依据
- **THEN** 系统 MUST 不自动授予这些新功能
- **AND** MUST 将该旧权限列为待核对
