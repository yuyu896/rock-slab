## REMOVED Requirements

### Requirement: 对账模块导航占位

**Reason**: 对账功能已不再是仅管理员可见的占位页，需要按账号权限、供应商查看前置和数据范围提供真实业务入口。

**Migration**: 使用新的对账权限和数据范围要求替换占位路由守卫；保留已有对账数据和任务。

## ADDED Requirements

### Requirement: 对账读取权限必须控制供应商信息

对账任务列表、详情和导出 MUST 同时要求“查看对账”和“查看供应商字典”。“维护对账” MUST 以前述两项查看权限为前置，并额外控制差异处理和归档；预览、导入和替换供应商订单 MUST 同时具备“查看对账”“查看供应商字典”和“维护对账”。仅有维护权限 MUST NOT 允许进入对账页面、读取任务或导出。

#### Scenario: 缺少任一查看前置
- **WHEN** 用户持有“维护对账”但缺少“查看对账”或“查看供应商字典”任一权限
- **THEN** 前端 MUST 不显示对账入口，列表、详情、导出、预览和导入接口 MUST 被拒绝
- **AND** 不得通过未决摘要或错误信息返回供应商编号、名称

#### Scenario: 完整对账权限
- **WHEN** 用户持有“查看对账”和“查看供应商字典”
- **THEN** 用户可按其数据范围读取并导出对账数据
- **AND** 只有另持“维护对账”时才可处理差异、归档、预览、导入或替换订单

#### Scenario: 维护权限不能单独导出
- **WHEN** 用户持有“查看对账”“查看供应商字典”和“维护对账”并请求导出
- **THEN** 导出接口 MUST 仍要求“查看对账”，并使用查看权限控制导出行为

### Requirement: 对账数据必须按数据范围裁剪

对账任务、比较结果、差异和导出 MUST 只包含用户当前数据范围内的分公司；任务含范围外比较记录且无法安全裁剪时，有限范围用户不得看到该任务的范围外内容。

#### Scenario: 供应商订单跨范围
- **WHEN** 一个对账任务同时包含范围内和范围外分公司记录
- **THEN** 有限范围用户只能看到可安全裁剪的范围内记录
- **AND** 归档等需要完整任务视图的操作 MUST 被拒绝
