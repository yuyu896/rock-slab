## ADDED Requirements

### Requirement: 系统必须使用确认后的统一权限目录

系统 MUST 使用一份版本化权限目录提供稳定权限码、中文名称、模块、说明、前置权限和历史状态。新目录 MUST 只暴露确认后的查看、编辑、删除草稿、审批和独立业务权限。

#### Scenario: 流转编辑权限合并
- **WHEN** 管理员打开采购、领用、调拨或回收权限目录
- **THEN** 页面显示对应的“编辑”权限
- **AND** 创建、编辑、提交、撤回和适用的批量导入 MUST 由该编辑权限覆盖
- **AND** 旧的创建、提交、撤回、导入权限码 MUST NOT 可新授予

#### Scenario: 盘点编辑权限合并
- **WHEN** 管理员打开盘点权限目录
- **THEN** 页面显示“查看盘点任务”“编辑盘点”和“审批盘点任务”
- **AND** 创建、维护、导入、重新盘点、删除和作废 MUST 由“编辑盘点”覆盖
- **AND** `view_inventory_report` 等旧码 MUST NOT 可新授予

### Requirement: 依赖查看权限的操作必须由目录声明前置关系

目录 MUST 声明每个写操作、删除操作和审批操作所需的全部查看权限。前置关系 MUST 区分“全部前置”与“按明细条件前置”，不得由查看权限隐式授予写权限。

#### Scenario: 采购编辑前置
- **WHEN** 目录返回“编辑采购入库单”
- **THEN** 其前置权限 MUST 同时包含“查看采购入库单”和“查看品目”

#### Scenario: 实例操作跨模块前置
- **WHEN** 目录返回“编辑实例档案”或“更换使用人和部门”
- **THEN** 编辑实例档案 MUST 同时要求实例档案查看和供应商字典查看
- **AND** 更换使用人和部门 MUST 同时要求实例档案查看和部门字典查看

### Requirement: 归还权限模块必须从新目录移除

新目录 MUST NOT 提供归还入库的查看、创建、编辑、删除、提交、撤回或审批权限。旧归还码 MUST 只能作为历史迁移记录返回，不得新授予或作为页面入口权限。

#### Scenario: 归还权限不可新授予
- **WHEN** 管理员编辑普通账号的权限
- **THEN** 权限目录中 MUST NOT 出现可勾选的归还权限
- **AND** 旧归还码如存在 MUST 显示为历史权限而非可选权限

#### Scenario: 归还页面不可进入
- **WHEN** 用户访问归还入库路径或导航
- **THEN** 系统 MUST 不显示归还入口并拒绝归还页面路由
- **AND** 历史归还数据 MUST 仍可被内部台账、报表和审计逻辑读取

### Requirement: 历史权限码迁移必须可审查

系统 MUST 提供只读迁移预览，展示旧权限、新权限候选、数据范围变化和无法无损映射项。没有明确映射的旧权限 MUST NOT 自动扩大为多个新权限。

#### Scenario: 无损映射预览
- **WHEN** 管理员运行权限迁移预览
- **THEN** 每个账号 MUST 显示迁移前后权限和范围差异
- **AND** 无法确认的旧权限 MUST 标记为待核对

#### Scenario: 迁移失败恢复
- **WHEN** 已确认迁移在写入过程中失败
- **THEN** 系统 MUST 使用迁移前快照恢复权限和数据范围
- **AND** MUST 保留失败审计记录

### Requirement: 查看审计日志不得授予普通岗位

“查看审计日志”MUST 仅作为系统管理员的内置能力。授权目录和权限分配页 MUST NOT 将其作为普通员工可授予项；全组织数据范围或查看权限矩阵 MUST NOT 隐式授予审计日志访问权。

#### Scenario: 普通员工权限目录不提供审计日志授权
- **WHEN** 管理员在权限分配页为任何普通岗位员工配置权限
- **THEN** 页面 MUST NOT 提供可勾选的“查看审计日志”权限
- **AND** 授权保存 API MUST 拒绝为普通员工新增该权限

#### Scenario: 系统管理员使用内置审计访问
- **WHEN** 系统管理员进入审计日志页面
- **THEN** 管理员 MUST 按系统管理员身份访问审计功能
- **AND** 系统 MUST NOT 要求在普通账号授权记录中勾选“查看审计日志”
