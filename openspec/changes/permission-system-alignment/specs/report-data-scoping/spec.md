## ADDED Requirements

### Requirement: 统计报表权限必须归入工作台与通知

权限目录 MUST 将 `view_reports` 的中文名称保持为“查看统计报表”，模块归属改为“工作台与通知”。该权限仍只允许报表页面和报表专属接口，不授予工作台页面入口。

#### Scenario: 报表权限不打开工作台页面
- **WHEN** 用户只持有查看统计报表
- **THEN** 用户 MUST 能进入报表页
- **AND** MUST 不能因该权限进入工作台页面

### Requirement: 共享汇总接口允许两种查看权限

工作台概览、分公司汇总和状态汇总接口 MUST 允许“查看工作台”或“查看统计报表”任一权限，并按当前数据范围裁剪。

#### Scenario: 报表用户读取共享汇总
- **WHEN** 用户只有查看统计报表
- **THEN** 用户 MUST 能读取共享汇总接口
- **AND** 返回数据 MUST 仅包含其当前数据范围

### Requirement: 流转导出必须按请求类型隔离

流转导出接口 MUST 在构建 Excel 前按请求 `type` 过滤单据类型；查看其他类型的权限不得导致其他类型数据混入当前模板。

#### Scenario: 请求采购类型
- **WHEN** 请求类型为采购
- **THEN** 导出文件 MUST 只含采购入库明细
