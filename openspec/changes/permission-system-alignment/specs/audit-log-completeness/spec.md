## ADDED Requirements

### Requirement: 审计日志仅管理员访问并按数据范围过滤

审计日志页面、导航、路由及全部读取接口 MUST 仅允许系统管理员访问；其他岗位 MUST NOT 获得“查看审计日志”权限，也不得因伪造权限码或请求参数绕过管理员身份校验。系统管理员查询日志时仍 MUST 按当前数据范围过滤；全组织数据范围可查看全量日志。

#### Scenario: 非系统管理员不能访问审计日志
- **WHEN** 普通账号直接请求审计日志列表、详情、统计或活跃度接口，或尝试打开审计日志页面
- **THEN** 后端 MUST 拒绝请求且前端 MUST 不显示审计日志入口

#### Scenario: 系统管理员按数据范围查询日志
- **WHEN** 系统管理员查询审计日志
- **THEN** 资源分公司不在其范围内的日志 MUST 不出现在列表、详情、统计或活跃度接口

#### Scenario: 无法映射的日志隐藏
- **WHEN** 数据范围有限的审计日志查询遇到登录、权限变更、全局字典或无法关联业务资源的日志
- **THEN** 这些日志 MUST 被隐藏
- **AND** 全组织范围的系统管理员可查看

### Requirement: 越界快照不得泄露

当日志本身可见但前后快照包含范围外数据且无法安全裁剪时，接口 MUST 保留日志元数据并隐藏前后快照。

#### Scenario: 快照无法裁剪
- **WHEN** 数据范围有限的审计查询读取可见资源日志且快照含范围外分公司字段
- **THEN** 响应 MUST 返回日志基本信息
- **AND** MUST 不返回无法安全裁剪的快照
