## ADDED Requirements

### Requirement: 所有确认的写操作必须校验查看前置

品目、部门、供应商、员工、组织、资产台账、实例档案、流转单和盘点写接口 MUST 同时校验目录声明的查看权限和写权限。实例和字典候选接口 MUST 使用相同前置。

#### Scenario: 目录写操作缺查看权限
- **WHEN** 用户直接调用新增品目、导入台账、编辑实例或创建流转单接口但缺少对应查看权限
- **THEN** 接口 MUST 返回 403 或 400
- **AND** 不得返回不必要的完整候选数据

### Requirement: 筛选器和实例下钻必须受对应查看权限控制

资产台账分公司筛选 MUST 要求组织架构查看，品目筛选 MUST 要求品目查看，实例下钻 MUST 要求实例档案查看。实例编辑供应商候选 MUST 要求供应商字典查看；更换使用人部门候选 MUST 要求部门字典查看和实例档案查看。

#### Scenario: 无实例查看隐藏下钻
- **WHEN** 用户只有资产台账查看权限但没有实例档案查看权限
- **THEN** 台账页面 MUST 隐藏实例下钻入口
- **AND** 直接调用下钻接口 MUST 被拒绝

### Requirement: 盘点锁期间台账不得入账

盘点锁定期间，资产台账导入确认和手工调整 MUST 被拒绝；预览可返回校验结果但不得产生调整单或数量变化。

#### Scenario: 手工调整撞盘点锁
- **WHEN** 用户在锁定分公司提交台账手工调整
- **THEN** 接口 MUST 返回明确的盘点锁错误
- **AND** 台账数量和调整记录 MUST 保持不变

### Requirement: 所有导入文件必须原子校验

资产台账、品目和盘点导入 MUST 在任一行错误时回滚整份文件；错误信息 MUST 只暴露完成校验所需的行号、编号和字段。

#### Scenario: 导入错误行不部分成功
- **WHEN** 文件含一行未登记品目或格式错误
- **THEN** 导入 MUST 整份驳回
- **AND** 有效行 MUST 不落库
