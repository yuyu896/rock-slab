## MODIFIED Requirements

### Requirement: 权限分配页必须按员工配置账号权限

权限分配页 SHALL 以员工账号为中心，展示账号资料、数据范围和当前业务权限。权限按中文模块分组显示，内部权限码不得作为授权文案。管理员保存前 SHALL 看到权限和范围差异。

#### Scenario: 按中文目录显示
- **WHEN** 管理员打开员工权限配置
- **THEN** 页面 MUST 显示中文模块和权限名称
- **AND** MUST NOT 显示已废弃权限的可勾选控件

#### Scenario: 查看前置置灰
- **WHEN** 员工未勾选某模块查看权限
- **THEN** 依赖该查看权限的编辑、删除或审批复选框 MUST 置灰且不可勾选
- **AND** 勾选查看后，依赖权限 MUST 可独立选择

#### Scenario: 取消查看自动清理
- **WHEN** 管理员取消一个已被依赖的查看权限
- **THEN** 页面 MUST 自动取消所有依赖权限
- **AND** MUST 明确提示被清除的权限名称

### Requirement: 权限保存接口必须和授权页依赖一致

统一授权保存接口 MUST 校验目录声明的全部前置权限，并在一个事务中保存权限和数据范围。接口不得因为前端未置灰而接受非法组合。

#### Scenario: 直接 API 提交非法组合
- **WHEN** 客户端绕过页面提交缺少查看前置的权限列表
- **THEN** 接口 MUST 返回可理解的校验错误
- **AND** 现有授权和数据范围 MUST 保持不变

### Requirement: 权限矩阵必须保持独立只读职责

`view_permission_matrix` MUST 独立控制矩阵读取；拥有该权限的非 admin 用户只能查看全体员工的实际权限、组织归属和数据范围，不能修改授权。权限分配仍仅系统管理员可用。

#### Scenario: 矩阵查看与权限分配分离
- **WHEN** 非 admin 用户持有 `view_permission_matrix` 但没有管理员身份
- **THEN** 用户 MUST 能读取矩阵
- **AND** MUST 不能访问授权保存接口或权限分配编辑页面
