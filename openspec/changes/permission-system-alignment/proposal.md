## Why

当前权限目录、授权页面和后端接口仍有旧的细分权限码、缺少查看前置、旧审批人名单路由和未收敛的数据范围，导致授权页展示的权限职责与实际可执行行为不一致。后续讨论又明确了岗位默认授权、草稿仅创建人可见和操作、审计日志仅系统管理员可用及员工账号硬删除时的历史保留规则；本变更需要同时固化这些最终决定。

## What Changes

- **BREAKING** 将基础资料、员工与组织、采购、领用、调拨、回收和盘点的旧创建/编辑/提交/撤回/导入等权限合并为确认后的“编辑”权限；删除草稿、审批、查看处置台账等明确独立的权限继续保留。
- **BREAKING** 从新授权目录移除归还入库模块及其权限；移除归还前端页面、路由和导航入口，保留历史归还数据供台账、报表和审计使用。
- 建立权限前置关系：授权页在缺少查看权限时置灰依赖操作，取消查看时自动清除并提示依赖权限，授权 API 和运行时接口同时校验前置权限。
- 将各资产流转和盘点审批改为岗位层级与数据范围规则：分公司行政只能审批本人创建的待审批单，行政组长及以上审批当前数据范围内的待审批单，系统管理员可审批任意待审批单，不再逐单指定审批人。
- 对账维护同时以前置“查看对账”和“查看供应商字典”为条件；维护权限不单独开放页面或导出。
- 根据已确认的岗位基线自动授予新员工和改岗员工默认权限；权限分配页勾选实际生效权限。现有在职员工首次同步时合并默认权限与既有明确授权，不扩大数据范围，不自动映射无法确认的旧权限。
- 岗位或分公司变化时重置到新分公司默认数据范围；改岗按新岗位重置业务权限，单独换分公司保留业务权限。后续修改岗位基线时先展示影响并由管理员确认，保留个人追加和取消。
- **BREAKING** 采购、领用、调拨和回收草稿仅创建人可查看和操作，系统管理员也无例外；按权限和数据范围删除员工账号时，清除未提交流转草稿及个人通知，保留待审批单、盘点任务和其他历史业务记录。
- 更新权限说明和模块归属：统计报表归入工作台与通知；工作台队列统一称为“待处理事项”；对账、审计日志、集团名称、资产台账、实例档案和导出行为补齐已确认的范围限制。
- 将审计日志限制为系统管理员专属入口和接口；其他岗位不得被授予该权限。
- 将旧权限码保留为不可新授予的历史记录，提供只读迁移预览和逐账号核对结果，不静默扩大旧权限的能力。

## Capabilities

### New Capabilities

- `permission-catalog-alignment`: 维护确认后的中文权限目录、权限合并、查看前置、历史权限码和归还模块移除规则。
- `approval-scope-routing`: 为采购、领用、调拨、回收和盘点提供统一的岗位层级与数据范围审批判定。

### Modified Capabilities

- `management-permissions`: 更新账号级操作权限目录、前置关系、历史权限迁移、集团名称全组织范围和写操作校验。
- `permission-matrix-view`: 更新授权页的前置置灰、自动清除提示、中文目录分组和只读矩阵职责。
- `transfer-document-lifecycle`: 更新流转单编辑权限合并、导入/导出边界、审批范围、草稿仅创建人访问和归还模块移除。
- `write-authorization-scoping`: 更新流转、盘点、台账和实例写接口的查看前置、数据范围和盘点锁校验。
- `audit-log-completeness`: 增加系统管理员专属入口/接口，并按用户数据范围过滤日志及隐藏越界快照。
- `report-data-scoping`: 更新统计报表分类和流转导出严格按请求类型筛选的要求。
- `personnel-management`: 更新员工/组织写权限前置和集团名称的全组织范围限制。
- `position-appointment-permissions`: 根据确认的岗位权限基线自动授予权限，并同步权限分配页当前勾选、岗位变化和基线更新行为。
- `reconciliation`: 更新对账列表、详情、导入、预览和导出所需的供应商字典前置。

## Impact

- 后端权限目录、岗位基线与账号级授权/数据范围同步、授权保存 API、权限迁移、员工删除与历史外键处理、业务 ViewSet 权限校验、审批路由、审计日志查询、报表/对账接口和归还数据入口。
- 前端权限分配页、权限矩阵页、模块导航、流转/盘点/台账/实例操作入口、报表与对账页面，以及归还页面和路由。
- 新建、换岗和停用/重新启用员工的授权同步；现有在职员工基线补授；删除员工时对草稿、待审批业务、盘点任务、对账和审计数据的关联处理。
- 现有显式授权需要生成迁移预览；旧权限码和历史归还数据必须保留可追溯性，但不再产生新的可执行权限或归还页面入口。
