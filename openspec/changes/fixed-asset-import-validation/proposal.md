## Why

固定资产批量导入缺少分公司校验、关键列不强制、去重规则过严，需补全。

## What Changes

1. **分公司校验**：导入校验分公司在组织架构中存在（不存在→拒行）。
2. **必填列**：电脑序列号、分公司编号改必填（空→拒行）。
3. **五元组去重**：按 `(分公司 + 分公司编号 + 电脑序列号 + 所属部门 + 使用人)` 判定表内重复上传（全同才算重复）。
4. **移除 DB 约束**：移除旧的 `(分公司 + 序列号)` 唯一约束（与新五元组规则冲突）。

> 部分代码已在中途改好（分公司校验、去重 key、去 DB 约束已应用），此提案补全必填校验。

## Capabilities

### New Capabilities
- `fixed-asset-import-validation`: 固定资产导入校验——分公司存在、电脑序列号/分公司编号必填、五元组表内去重。

## Impact

- 后端 `assets/views.py`（import_excel）、`assets/models.py`（去约束）、迁移。
