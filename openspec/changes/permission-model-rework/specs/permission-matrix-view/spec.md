## ADDED Requirements

### Requirement: 权限分配三步流程（选人→岗位→任命）+ 实时预览
权限分配页 SHALL 提供三步流程：①选择员工 → ②选择岗位模板（操作码按模板预填，可增删）→ ③任命节点（按模板提示节点类型，写入对应树节点负责人字段）。页面 SHALL 常驻实时权限预览：该员工当前生效数据范围（任命 ∪ 额外授权展开的分公司数或「全部」）与持有操作码清单。页面 SHALL 保留「特例调整」区，支持对组织节点授权（ManagementScope）与单个操作码授权（OperationGrant）的手工增删（跨区兼管等特例）。

#### Scenario: 三步完成一次任命
- **WHEN** 管理员依次选员工、选岗位「大区负责人」、任命为区域 R 负责人并保存
- **THEN** 员工岗位更新、模板操作码写入授权表、区域 R 的 manager 更新；预览显示范围含 R 旗下全部分公司

#### Scenario: 实时预览反映任命
- **WHEN** 在第③步选择任命节点（未保存）
- **THEN** 预览区即时显示「若保存后」的生效范围与操作码变化

#### Scenario: 特例手工调整仍可用
- **WHEN** 管理员在特例区为员工追加「分公司 B 节点授权」或勾选单个操作码
- **THEN** 授权记录即时创建/删除，预览同步更新

### Requirement: 权限矩阵页（岗位×操作码 + 用户生效权限卡）
系统 SHALL 提供权限矩阵页（/admin/permission-matrix，仅 admin 可见），Excel 式朴素呈现：
- **岗位模板矩阵**：行 = 操作码、列 = 岗位（或互换），✔ 标记该岗位模板预填的操作码（只读）；
- **用户生效权限卡**：每行一位员工——姓名、岗位、任命节点、额外授权（节点/全部数据）、生效范围（「全部」或 N 个分公司）、持有操作码；admin 行显示「全部权限（内置）」。

#### Scenario: 矩阵展示模板预填
- **WHEN** admin 打开矩阵页
- **THEN** 岗位×操作码矩阵按后端模板渲染，director 列含 view_reports 等 8 项 ✔

#### Scenario: 生效权限卡呈现全员
- **WHEN** admin 查看用户生效权限卡
- **THEN** 每位员工一行，任命节点与额外授权分列展示，生效范围为「全部」或具体分公司数量

### Requirement: 全员生效权限总览接口
系统 SHALL 提供 `GET /api/permissions/effective`（仅 admin）：一次返回全员生效权限——每人 `{员工, 岗位, 任命节点列表, 额外授权列表, 持有操作码, 生效范围摘要（all 或分公司数）}`，全部为实时派生只读值。

#### Scenario: 总览反映任命
- **WHEN** 某员工刚被任命为行政组长后请求总览
- **THEN** 该员工记录的任命节点含该行政组，生效范围含组内分公司数

#### Scenario: 非 admin 拒绝
- **WHEN** 非 admin 用户请求 effective 接口
- **THEN** 返回 403

### Requirement: 当前用户权限摘要扩展
`GET /api/permissions/me` SHALL 在既有字段之上返回当前用户的任命节点列表与生效范围摘要（all 或分公司数），供前端（如移动端审批按钮）以操作授权判断能力。

#### Scenario: 移动端审批按钮按授权显示
- **WHEN** 持有 approve_transfer 授权（或 admin）的用户打开移动端审批中心
- **THEN** 审批操作可用；无该授权的用户不可见审批操作入口
