## Why

实例点选体验与档案展示两处摩擦：①回收/调拨/归还的实例选择用多选面板（勾选+拉到底点「完成」），分公司百余台实例时要滚很久，且与领用出库「点选即定收起」的顺手感不一致；②实例档案生平（行编辑弹窗右栏）「类型」列直接显示英文动作名（purchase/assign/…），业务读不懂，弹窗整体也偏小。

## What Changes

- **实例点选统一单选模式**：所有单据创建页（领用/归还/调拨/回收）的实例行统一「点选即定并收起」（领用现状 InstancePicker single 模式）；**多选模式退役**（勾选框+底部「完成」按钮及多选分支删除）；行模型变为**实例行一行一台**（数量随点选自动=1，已禁用的数量输入维持），多台=多行（+添加行）
- **后端零改动**：N 行×1 实例与 1 行×N 实例 API 完全等价，`len(instances)==数量` 矩阵、按实例去重预检照旧；UI 编辑路径仅采购单（无实例行），无历史多选行包袱
- **生平类型中文化**：类型列渲染 `TRANSFER_TYPES` 中文标签（采购入库/领用出库/归还入库/调拨/回收），复用既有 constants 映射
- **行编辑弹窗扩大**：承载生平的双栏弹窗（左编辑右生平）宽度 920px → 1160px

## Capabilities

### New Capabilities
- `instance-picking-ux`：单据创建页实例点选交互（单选点选即定、一行一台、多选退役）与实例档案生平展示（中文类型标签、弹窗尺寸）

### Modified Capabilities
（无——API 契约矩阵不变，本次纯前端交互与展示）

## Impact

- 前端：`InstancePicker.vue`（多选分支与完成按钮删除，组件简化为单选）；`TransferLinesEditor.vue`（`:single` 恒真/属性退役、单选回调数量置 1）；`FixedAssetList.vue`（生平类型中文标签、弹窗 920→1160）
- 后端：零改动、零迁移
- 范围外：后端多实例行 API 契约保持（导入等程序化路径不受影响）；移动端领用已是单选不动；实例去重跨行提示逻辑照旧
