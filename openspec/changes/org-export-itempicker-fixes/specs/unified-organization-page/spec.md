## MODIFIED Requirements

### Requirement: 员工操作（创建 / 移动 / 删除）

员工列表上方 MUST 提供「创建 / 移动 / 删除员工」，受 `manage_users` 权限控制。创建默认挂当前节点。**移动员工 MUST 通过弹窗选择目标分公司**；分公司下拉支持清空（置空即将员工移至无分公司归属状态）；**提交 MUST 仅写 branch**（区域/行政组由分公司沿树派生，不再同步写入任何员工字段）。移动弹窗 MUST NOT 对分公司做必选校验——允许提交空值将员工移出任何分公司。

#### Scenario: 移动弹窗分公司可清空

- **WHEN** 点击「移动」打开移动弹窗
- **THEN** 分公司选择器带有清空按钮，用户可清空选择以表示移出所有分公司

#### Scenario: 移动员工到无分公司归属

- **WHEN** 用户清空分公司选择后确认移动
- **THEN** 员工的 `branch` 更新为 null，员工在集团根节点员工列表中可见

#### Scenario: 移动员工只改分公司

- **WHEN** 确认移动，选中目标分公司
- **THEN** 员工的 `branch` 改为目标分公司，无其他组织字段被写入
