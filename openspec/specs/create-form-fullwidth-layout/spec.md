# create-form-fullwidth-layout Specification

## Purpose
所有"新建/创建"独立页面与列表页共用同一布局纪律：容器撑满内容区，不做弹窗式限宽居中（asset-model-v2.md 第八节 UI 规范，2026-08-27 修宪）。
## Requirements
### Requirement: 新建/创建页撑满内容区

所有"新建/创建"独立页面（流转四单创建页、盘点任务创建页等）SHALL 撑满内容区宽度，与列表页同一布局纪律；页面容器 MUST NOT 整体限宽居中（禁止 max-width + margin: 0 auto 的弹窗观感）。表单栅格在超宽屏 MAY 限制单列最大宽度，明细行表格 SHALL 随容器撑满。

#### Scenario: 流转四单新建页撑满

- **WHEN** 用户在超宽屏（如 1920px 内容区）打开采购入库/领用出库/调拨/回收任一新建页
- **THEN** 页面卡片与明细行表格撑满内容区宽度，不再呈现 960px 居中弹窗观感

#### Scenario: 盘点任务创建页撑满

- **WHEN** 用户打开盘点任务创建页
- **THEN** 页面容器不再 640px 限宽，表单字段以两列栅格撑满内容区（任务名称可跨列）

#### Scenario: 超宽屏表单列宽有上限

- **WHEN** 内容区宽度超过表单两列栅格的合理阅读宽度
- **THEN** 表单栅格单列宽度有最大值约束，输入控件不会拉成整行超长；页面卡片与明细表格仍撑满容器
